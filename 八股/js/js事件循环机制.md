js是什么？
js是浏览器核心脚本语言，在早期html诞生时，网站是纯静态的页面，无任何交互能为，为了实现浏览器网站可以与用户交互的功能，js出现了，它的目的就是将静态网站变成**可交互的动态网站**

DOM (文档对象模型)
dom就是让用户操作网页的一个实现技术，浏览器将html解析成节点对象，js可操作dom。

js脚本在哪里执行？
js脚本必须在特定的环境下才能执行，常见的环境有：浏览器、node js环境、小程序或app等用用js引擎的环境等。

js为什么是单线程的？
若js是多线程，js在操作dom时，如果有多个地方同时修改了一处dom，那么会引起dom操作冲突。
因此js设计为单线程，这样做避免了dom操作冲突，但是引发了一个新的问题，当执行一些比较耗时的任务时（网络请求、定时器、dom操作），js线程会被阻塞，后续任务被迫暂停执行，这会导致页面卡死，影响页面加载，从而影响用户体验。

因此异步出现了
它允许js在执行耗时任务时，可以将耗时任务放在另一个地方执行，执行完毕后，再在js主线程中执行它的回调函数。

js事件循环机制就是异步的实现方法

js事件循环机制是什么？
既要满足js单线程，又要满足异步，而出现的机制（二者的桥梁）
核心是js按照优先级顺序执行任务
任务：
	同步任务：变量、函数、
	异步任务：
		宏任务：
			浏览器的定时器
			ajax和fetch等网络请求
			dom事件回调
			script标签
		微任务：promise、queueMicoTask()
		
1. 执行所有同步代码，同时收集异步任务，将相应的回调函数放入相应的队列中
2. 清空微任务队列，将微任务的回调一次加入执行栈，依次执行，直到队列被清空
3. UI渲染，浏览器更新页面（修改的dom生效）
4. 执行一个宏任务，将一个宏任务回调放入执行栈，执行完毕后，重复步骤2
5. 重复步骤2-4直到所有任务执行完毕。

一次事件循环：执行一个宏任务 -> 清空微任务队列 -> UI渲染
