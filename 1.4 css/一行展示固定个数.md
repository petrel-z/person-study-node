一行固定展示3个图片，但是父盒子宽度不固定，子元素的宽度也不固定
如何保证父盒子不管怎么变，子元素的宽度随之改变，且一行展示固定个数，间距也固定

1. flex+calc函数动态设置宽度width: calc((100% - 32rpx) / 3)
```css
display: flex;
flex-wrap: wrap;
gap: 16rpx;
子：
flex: 0 0 calc(33.333% - 11rpx);
```
2. grid布局：
```css
display: grid;
grid-template-columns: repeat(3, 1fr);
gap: 16rpx;
```
3. flex+百分比
```css
display: flex;
flex-wrap: wrap;

子：
/* 图片样式 */
width: 33.333%;
margin-right: 16rpx;
margin-bottom: 16rpx;
```
