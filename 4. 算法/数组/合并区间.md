# 思路：
1. 指定边界，查看边界是否重合
	1. 重合则更新边界
	2. 不重合则开始新的边界

三种关系，两种操作
1. 相交，更新边界
2. 不相交，重新确定边界

# 代码
```js
/**
 * @param {number[][]} intervals
 * @return {number[][]}
 */
var merge = function (intervals) {
    if (intervals.length <= 1) {
        return intervals;
    }
    intervals.sort((a, b) => a[0] - b[0]);
    const res = [];
    let cur = intervals[0];
    for (let i = 1; i < intervals.length; i++) {
        if (intervals[i][0] > cur[1]) {
            // 不相交
            res.push(cur);
            cur = intervals[i];
        } else {
            // 相交,确定右边界
            if (cur[1] < intervals[i][1]){
                cur[1] = intervals[i][1];
            }
        }
    }
    res.push(cur);
    return res;
};
```

# 注意：
循环结束后，最后一个结果要单独加入到res中
因为相交后，要重新更新边界，如果循环结束，则新更新的边界未加入到数组中

为什么一定要先给数组排序呢？
因为可能会遇见：先遇到大区间，然后遇到小的区间，这个时候，我们的判断就不好确定了
为了统一成固定的情况，只考虑两种情况：有重叠区间和无重叠区间
排序之后，只需要考虑上一个区间的右边界与下一个区间的左边界的重叠情况
重叠了就更新区间的右边界，不重叠就把下一个区间当成新的区间
