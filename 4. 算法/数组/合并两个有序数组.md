https://leetcode.cn/problems/merge-sorted-array/
# 要求：
不返回新的数组，而是返回其中一个数组

# 思路1：
1. 创建一个新的数组，排序后，将新的数组赋值给nums1

```js
/**
 * @param {number[]} nums1
 * @param {number} m
 * @param {number[]} nums2
 * @param {number} n
 * @return {void} Do not return anything, modify nums1 in-place instead.
 */
var merge = function(nums1, m, nums2, n) {
    let res = [];
    let len = m + n;
    let i = 0;
    let j = 0;
    while(i < m && j < n){
        if(nums1[i] > nums2[j]){
            res.push(nums2[j++]);
        }else{
            res.push(nums1[i++]);
        }
    }
    while(i < m){
        res.push(nums1[i++]);
    }
    while(j < n){
        res.push(nums2[j++]);
    }
    for(let k = 0; k < len; k++){
        nums1[k] = res[k];
    }
};

```
# 思路2：
从后往前排序
三个指针
m指向nums1有效数的最右边
n指向nums2最右边
i指向nums1最右边
比较nums1[m] 和nums2[n]
小的数，指针往左移，并更新nums1右侧，i左移
最后如果m和n不相等
m剩余，则不需要变动
n剩余，则需要将nums2剩余元素更新到nums1中

```js
/**
 * @param {number[]} nums1
 * @param {number} m
 * @param {number[]} nums2
 * @param {number} n
 * @return {void} Do not return anything, modify nums1 in-place instead.
 */
var merge = function(nums1, m, nums2, n) {
    let i = n + m - 1;
    m--,n--;
    while(m >= 0 && n >= 0){
        if(nums1[m] > nums2[n]){
            nums1[i--] = nums1[m--];
        }else{
            nums1[i--] = nums2[n--];
        }
    }
    while(n >= 0){
        nums1[i--] = nums2[n--];
    }
};
```
