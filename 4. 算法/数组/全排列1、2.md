# 全排列
https://leetcode.cn/problems/permutations/description/
回溯

**关键信息：** 数组中的元素不重复，返回所有排列结果

for循环决定横向深度
递归体决定纵向深度

确定递归**结束条件**：
当纵向递归到叶子节点时，就收获该叶子节点
由于没有重复元素，不用考虑排列结果有重复的情况

得用一个数组来记录元素是否使用过

递归**参数**是什么？
1. 传入要排列的数组
2. 记录元素是否使用过的数组
3. 记录最终结果的数组(可定义为全局变量)
4. 记录临时结果的数组(可定义为全局变量)

```js
/**
 * @param {number[]} nums
 * @return {number[][]}
 */
var permute = function(nums) {
    let res = [];
    let path = [];
    let used = Array.from({length: nums.length}, () => false);
    recursion(nums, used, res, path);
    return res;
};

let recursion = (nums, used, res, path) => {
    if(path.length === nums.length){
        res.push([...path]);// 误区
        return;
    }
    for(let i = 0; i < nums.length; i++){
        if(!used[i]){
            path.push(nums[i]);
            used[i] = true;
            recursion(nums, used, res, path);
            used[i] = false;
            path.pop();
        }
       
    }
}
```

### 误区：
`res.push([...path]); `容易写成`res.push(path); `
因为如果直接push path，添加到res的是path数组的引用，导致path元素改变，res中的结果也会跟着改变
### 🌰 举个例子

假设：
`nums = [1, 2]`
递归第一次结束时：
`path = [1, 2] res = [[1, 2]]`

接着你回溯 (`path.pop()`)，此时：
`path = [1]`

但是！  
因为 `res[0]` 存的其实是 **同一个 path 引用**，  
所以 `res` 里的 `[1, 2]` 也变成了 `[1]`。😱


# 全排列2
https://leetcode.cn/problems/permutations-ii/
回溯

**关键信息：** 数组包含重复元素

步骤：
1. 先给数组排序
	为了让重复的元素排在一起


**结束条件：** 
2. 当临时结果数组长度与原数组长度相等

**传入参数：** 
1. 原数组
2. used数组，记录使用过的元素
3. res、path数组（可放在全局）

难点：如何避免出现重复的排列？
排列过程中如果选排的元素和上一次重复了，就停止该元素的排列
横向的元素不能重复，但是纵向的能重复

```js
/**
 * @param {number[]} nums
 * @return {number[][]}
 */
var permuteUnique = function(nums) {
    let res = [];
    let path = [];
    let used = Array.from({length: nums}, () => false);
    nums.sort();
    recursion(nums, used, res, path);
    return res;
};

let recursion = (nums, used, res, path) => {
    if(path.length === nums.length){
        res.push([...path]);
        return;
    }

    for(let i = 0; i < nums.length; i++){
        if(i > 0 && nums[i] === nums[i - 1] && !used[i - 1] ){
            continue;
        }
        if(!used[i]){
            used[i] = true;
            path.push(nums[i]);
            recursion(nums, used, res, path);
            used[i] = false;
            path.pop();
        }
    }
}
```
