如何判断它是**不重复**的**最长**的子字符串
不重复选map或set
最长选滑动窗口

滑动窗口的原理：
获取连续子区间

# 方法一：
如何移除map中重复元素之前的元素：
清除map，从重复元素的下一个元素开始，重新添加到map中
最后还需要判断一下max和map.size
```js
/**
 * @param {string} s
 * @return {number}
 */
var lengthOfLongestSubstring = function(s) {
    let map = new Map();
    let max = 0;
    let index = 0;
    for(let i = 0; i < s.length; i++){
        let ch = s.charAt(i);
        if(map.has(ch)){
            index = map.get(ch);
            i = index;
            if(max < map.size){
                max = map.size;
            }
            map.clear();
            continue;
        }
        map.set(ch, i);
    }
    max = Math.max(max, map.size);
    return max;
};
```

# 方法二：
遇到重复的字符后，删除map的第一个字符就是那个重复的字符

```js
/**
 * @param {string} s
 * @return {number}
 */
var lengthOfLongestSubstring = function(s) {
    let set = new Set();
    let r = -1;
    let max = 0;
    for(let i = 0;i < s.length; i++){
        if(i != 0){
            set.delete(s.charAt(i - 1));
        }
        while(r + 1 < s.length && !set.has(s.charAt(r + 1))){
            set.add(s.charAt(r + 1));
            r++;
        }
        max = Math.max(max, r - i + 1);
    }
    return max;
};
```
