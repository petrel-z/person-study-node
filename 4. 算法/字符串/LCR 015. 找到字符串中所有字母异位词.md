哈希+字符串+滑动窗口

用哈希表存第二个字符串（变位词）
连续遍历目标字符串
构造长度为 第二个字符串长度的 滑动窗口
滑动窗口在滑动过程中，不断的抹去前边的数据，重新补充新的数据到滑动窗口中

```js
/**
 * @param {string} s
 * @param {string} p
 * @return {number[]}
 */
var findAnagrams = function (s, p) {
    let slen = s.length;
    let plen = p.length;
    let res = [];
    if(slen < plen){
        return res;
    }
    let srr = new Array(26).fill(0);
    let prr = new Array(26).fill(0);
    for(let i = 0; i < plen; ++i){
        ++srr[s[i].charCodeAt() - 'a'.charCodeAt()];// 让当前字符对应的数量自增
        ++prr[p[i].charCodeAt() - 'a'.charCodeAt()];
    }
    if(srr.toString() === prr.toString()){
        res.push(0);// 说明所以0开始就是变位词了
    }
    for(let i = 0; i < slen - plen; ++i){
        --srr[s[i].charCodeAt() - 'a'.charCodeAt()];
        ++srr[s[i + plen].charCodeAt() - 'a'.charCodeAt()];
        if(srr.toString() === prr.toString()){
            res.push(i + 1);
        }
    }
    return res;
};
```

c.charCodeAt()返回字符c的**Unicode**编码值
