 括号匹配+不确定性处理

（）*

# 方法一
## 思路：栈
一个栈来存左括号的下标
一个栈存星号的下标
遇到有括号，先弹出左括号的下标，再弹出星号的下标
字符串遍历完后，还需判断两个栈是否为不为空的情况
两个栈若都不为空，同时弹出两个栈的最后一个，比较下标，存左括号的下标应该小于存星号的下标，否则不是有效的字符串
最后再判断左括号的栈是否为空，为空才是有效的字符串
```js
/**
 * @param {string} s
 * @return {boolean}
 */
var checkValidString = function (s) {
    let len = s.length;
    let stack = [];
    let asterisk = [];
    for (let i = 0; i < len; i++) {
        let c = s.charAt(i);
        if (c === '(' ) {
            stack.push(i);
        } else if (c === '*') {
            asterisk.push(i);
        }else if (c === ')') {
            if(stack.length != 0){
                stack.pop();
            }else if(asterisk.length != 0){
                asterisk.pop();
            }else{
                return false;
            }
        }
    }
    while(stack.length != 0 && asterisk.length != 0){
        let i = stack.pop();
        let j = asterisk.pop();
        if(i > j){
            return false;
        }
    }
    return stack.length === 0;
};
```


# 方法二：
## 思路：贪心+区间

定义两个变量 
minOpen：目前最少数量的左括号
maxOpen：目前最多数量的左括号

遇到左括号
minOpen++
maxOpen++

遇到右括号
minOpen--
maxOpen--

遇到星号
minOpen--（作为左括号）
maxOpen++（作为右括号）

注意：
当遇到右括号时
若minOpen<0，继续减还是0
若maxOpen<0，则右括号太多

遍历完字符串
若minOpen == 0 且 maxOpen <= 0则成立

```js
/**
 * @param {string} s
 * @return {boolean}
 */
var checkValidString = function(s) {
    let minOpen = 0;
    let maxOpen = 0;
    for (let i = 0; i < s.length; i++){
        let c = s.charAt(i);
        if(c === '('){
            minOpen++;
            maxOpen++;
        }else if(c === ')'){
            minOpen--;
            maxOpen--;
        }else{
            minOpen--;
            maxOpen++;
        }
        if(minOpen < 0){
            minOpen = 0;
        }
        if(maxOpen < 0){
            return false
        }
    }
    return minOpen === 0;
};
```
