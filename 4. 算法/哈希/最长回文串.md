# 思路：
哈希表存放每个字符串中相同字符的个数
统计每种字符的偶数部分
最后再判断是否还有多余的字符串充当回文串中间那个字符。
```js
/**
 * @param {string} s
 * @return {number}
 */
var longestPalindrome = function(s) {
    let map = new Map();
    for(let i = 0 ; i < s.length; i++){
        let ch = s.charAt(i);
        if(map.has(ch)){
            let temp = map.get(ch);
            temp++;
            map.set(ch , temp);
        }else{
            map.set(ch, 1);
        }
    }
    let sum = 0;
    for(let value of map.values()){
        sum += Math.floor(value/2) * 2;
    }
    return sum < s.length ? ++sum : sum;
};
```

❌  sum += value/2 * 2;
value / 2 的结果是浮点数，不是自动向上取整，我们需要用Math.floor

时间复杂度： O(n)
空间复杂度：O(Σ)（字符种类数，最多 52 个字母或 128/256 个 ASCII 字符）
