- 时间复杂度：O(n + k)，k 为数据范围
- 空间复杂度：O(k)
- Out-place 外排序
- 稳定

# 思路
计数排序不是基于比较的排序，而是通过统计每个值出现的次数来排序
1. 找出数组中的最大值和最小值，确定数据范围
2. 统计每个值出现的次数，存入计数数组
3. 对计数数组做前缀和，确定每个值在结果数组中的位置
4. 从后往前遍历原数组，根据计数数组确定位置，放入结果数组

```js
/**
 * @param {number[]} nums
 * @return {number[]}
 */
var sortArray = function (nums) {
    if (nums.length <= 1) return nums;

    // 找出最大值和最小值
    let min = nums[0], max = nums[0];
    for (let num of nums) {
        if (num < min) min = num;
        if (num > max) max = num;
    }

    // 计数数组
    let range = max - min + 1;
    let count = new Array(range).fill(0);

    // 统计每个元素出现的次数
    for (let num of nums) {
        count[num - min]++;
    }

    // 前缀和，确定每个元素的位置
    for (let i = 1; i < range; i++) {
        count[i] += count[i - 1];
    }

    // 从后往前遍历，保证稳定性
    let res = new Array(nums.length);
    for (let i = nums.length - 1; i >= 0; i--) {
        let idx = nums[i] - min;
        res[count[idx] - 1] = nums[i];
        count[idx]--;
    }

    return res;
};
```

# 特点
1. **稳定排序**：从后往前遍历，保证相同元素的相对位置不变
2. **适用范围**：整数排序，且数据范围 k 不能太大
3. **非比较排序**：突破了 O(nlogn) 的比较排序下界

# 适用场景
1. 成绩排序（0-100 分）
2. 年龄排序（0-150 岁）
3. 其他数据范围有限的整数排序

# 不适用场景
1. 数据范围很大（如 1 到 10 亿）
2. 浮点数排序
3. 字符串排序
