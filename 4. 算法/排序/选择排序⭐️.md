- 时间复杂度：平均 O(n²)、最好 O(n²)、最坏 O(n²)
- 空间复杂度：O(1)
- In-place 内排序
- 不稳定

# 思路
遍历数组，每一轮从未排序部分选择最小（或最大）的元素
将其放到已排序部分的末尾（即未排序部分的起始位置）
重复这个过程，直到数组有序

```js
/**
 * @param {number[]} nums
 * @return {number[]}
 */
var sortArray = function (nums) {
    let n = nums.length;
    for (let i = 0; i < n - 1; i++) {
        let minIndex = i;
        // 从未排序部分找到最小值的索引
        for (let j = i + 1; j < n; j++) {
            if (nums[j] < nums[minIndex]) {
                minIndex = j;
            }
        }
        // 将最小值交换到已排序部分的末尾
        if (minIndex !== i) {
            [nums[i], nums[minIndex]] = [nums[minIndex], nums[i]];
        }
    }
    return nums;
};
```

# 注意
选择排序是**不稳定**的，因为交换操作可能会改变相同元素的相对位置

例如：[5, 8, 5, 2, 9]
第一轮选择最小值 2，与第一个 5 交换，变成 [2, 8, 5, 5, 9]
原来两个 5 的相对位置被改变了
