- 时间复杂度：平均 O(n²)、最好 O(n)、最坏 O(n²)
- 空间复杂度：O(1)
- In-place 内排序
- 稳定

# 思路
将数组分为已排序和未排序两部分，初始时第一个元素视为已排序
从第二个元素开始，依次将未排序部分的元素插入到已排序部分的正确位置
插入时，将已排序部分比当前元素大的值向后移动，腾出位置

```js
/**
 * @param {number[]} nums
 * @return {number[]}
 */
var sortArray = function (nums) {
    let n = nums.length;
    for (let i = 1; i < n; i++) {
        let cur = nums[i];
        let j = i - 1;
        // 将已排序部分比 cur 大的元素向后移动
        while (j >= 0 && nums[j] > cur) {
            nums[j + 1] = nums[j];
            j--;
        }
        // 插入到正确位置
        nums[j + 1] = cur;
    }
    return nums;
};
```

# 特点
1. **最好情况**：数组已经有序，时间复杂度为 O(n)
2. **适用场景**：数据量小、基本有序的数据
3. **稳定排序**：不会改变相同元素的相对位置

# 二分插入排序（优化）
用二分查找找到插入位置，减少比较次数，但移动次数不变

```js
var sortArray = function (nums) {
    let n = nums.length;
    for (let i = 1; i < n; i++) {
        let cur = nums[i];
        let left = 0, right = i - 1;
        // 二分查找插入位置
        while (left <= right) {
            let mid = Math.floor((left + right) / 2);
            if (nums[mid] > cur) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        }
        // 移动元素
        for (let j = i - 1; j >= left; j--) {
            nums[j + 1] = nums[j];
        }
        nums[left] = cur;
    }
    return nums;
};
```
