# 快速选择算法 (Quick Select)

快速选择算法用于在无序数组中找到**第 k 大（或小）**的元素，时间复杂度平均为 O(n)

## 思路
基于快速排序的 partition 思想：
1. 选择一个 pivot，将数组分为两部分
2. 根据 pivot 的位置判断第 k 大元素在哪一边
3. 只递归搜索包含目标的那一边（而不是像快排那样两边都搜）

```js
/**
 * 找到第 k 大的元素
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
function findKthLargest(nums, k) {
    const target = nums.length - k; // 第 k 大 = 第 (n-k) 小（从 0 开始）

    function quickSelect(left, right) {
        if (left === right) return nums[left];

        // 随机选择 pivot
        const pivotIndex = Math.floor(Math.random() * (right - left + 1)) + left;
        const pivot = nums[pivotIndex];

        // 分区
        let i = left, j = right;
        while (i <= j) {
            while (nums[i] < pivot) i++;
            while (nums[j] > pivot) j--;
            if (i <= j) {
                [nums[i], nums[j]] = [nums[j], nums[i]];
                i++;
                j--;
            }
        }

        // 判断第 k 大元素在哪一边
        if (target <= j) return quickSelect(left, j);
        if (target >= i) return quickSelect(i, right);
        return nums[target];
    }

    return quickSelect(0, nums.length - 1);
}
```

## LeetCode 215. 数组中的第 K 个最大元素

```js
/**
 * @param {number[]} nums
 * @param {number} k
 * @return {number}
 */
var findKthLargest = function(nums, k) {
    const target = nums.length - k;
    return quickSelect(nums, 0, nums.length - 1, target);
};

function quickSelect(nums, left, right, target) {
    if (left === right) return nums[left];

    // 随机选择 pivot 并交换到开头
    const pivotIndex = Math.floor(Math.random() * (right - left + 1)) + left;
    [nums[left], nums[pivotIndex]] = [nums[pivotIndex], nums[left]];

    const pivot = nums[left];
    let i = left + 1, j = right;

    while (i <= j) {
        while (i <= j && nums[i] < pivot) i++;
        while (i <= j && nums[j] > pivot) j--;
        if (i <= j) {
            [nums[i], nums[j]] = [nums[j], nums[i]];
            i++;
            j--;
        }
    }

    // 把 pivot 放回正确位置
    [nums[left], nums[j]] = [nums[j], nums[left]];

    // 判断 target 在哪一边
    if (j === target) return nums[j];
    if (j < target) return quickSelect(nums, j + 1, right, target);
    return quickSelect(nums, left, j - 1, target);
}
```

## 复杂度分析

| 情况 | 时间复杂度 | 说明 |
|------|-----------|------|
| 最好 | O(n) | 每次 pivot 都在中间 |
| 平均 | O(n) | 随机 pivot 期望 |
| 最坏 | O(n²) | 每次 pivot 都在边界（已排序数组） |
| 空间 | O(logn) | 递归栈深度 |

## 与快速排序的区别

| 快速排序 | 快速选择 |
|---------|---------|
| 对数组完全排序 | 只找第 k 大元素 |
| 递归左右两边 | 只递归一边 |
| 时间复杂度 O(nlogn) | 时间复杂度 O(n) |

## 其他解法：小顶堆

```js
function findKthLargest(nums, k) {
    // 维护大小为 k 的小顶堆
    const heap = [];

    for (let num of nums) {
        heap.push(num);
        heapifyUp(heap, heap.length - 1);

        if (heap.length > k) {
            heap[0] = heap.pop();
            heapifyDown(heap, 0);
        }
    }

    return heap[0];
}

function heapifyUp(heap, i) {
    while (i > 0) {
        const parent = Math.floor((i - 1) / 2);
        if (heap[i] < heap[parent]) {
            [heap[i], heap[parent]] = [heap[parent], heap[i]];
            i = parent;
        } else break;
    }
}

function heapifyDown(heap, i) {
    const n = heap.length;
    while (true) {
        let smallest = i;
        const left = 2 * i + 1;
        const right = 2 * i + 2;

        if (left < n && heap[left] < heap[smallest]) smallest = left;
        if (right < n && heap[right] < heap[smallest]) smallest = right;

        if (smallest !== i) {
            [heap[i], heap[smallest]] = [heap[smallest], heap[i]];
            i = smallest;
        } else break;
    }
}
```

时间复杂度：O(n log k)，适合 k 远小于 n 的情况
