- 时间复杂度：平均 O(nlogn)、最好 O(nlogn)、最坏 O(n²)
- 空间复杂度：O(1)
- In-place 内排序
- 不稳定

# 思路
希尔排序是插入排序的优化版本
选择一个增量序列，按增量将数组分组
对每组进行插入排序
逐渐缩小增量，直到增量为 1，此时整个数组有序

```js
/**
 * @param {number[]} nums
 * @return {number[]}
 */
var sortArray = function (nums) {
    let n = nums.length;
    // 增量从 n/2 开始，每次减半，直到 1
    for (let gap = Math.floor(n / 2); gap >= 1; gap = Math.floor(gap / 2)) {
        // 对每个分组进行插入排序
        for (let i = gap; i < n; i++) {
            let cur = nums[i];
            let j = i - gap;
            // 组内插入排序
            while (j >= 0 && nums[j] > cur) {
                nums[j + gap] = nums[j];
                j -= gap;
            }
            nums[j + gap] = cur;
        }
    }
    return nums;
};
```

# 增量序列
1. **Shell 原始序列**：n/2, n/4, n/8, ... 1（最坏 O(n²)）
2. **Hibbard 序列**：1, 3, 7, 15, ... 2^k-1（最坏 O(n^1.5)）
3. **Sedgewick 序列**：1, 5, 19, 41, ...（最坏 O(n^1.33)）

# 特点
1. **不稳定排序**：相同元素可能被分到不同组，相对位置可能改变
2. **突破 O(n²)**：通过分组插入，突破了传统插入排序的复杂度限制
3. **理解难度**：增量序列的选择会影响性能，但最优序列仍是开放问题
