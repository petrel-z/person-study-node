### 1. 找到链表里是否有环
#### 哈希表思路
定义一个Set变量，遍历链表
当这个节点能在Set里面找到，就说明有环
不能找到，就将这个头节点加到Set里面，再遍历下一个节点
如果遇到当前遍历的节点为null，说明没有环，也就能跳出循环
#### 快慢指针
一个快指针，一个慢指针
快指针一次走两步，慢指针走一步
如果有环，快指针一定会追上慢指针，因为快指针相对于慢指针，只多走了1步，快指针是以每次1步的速度追慢指针的
``` js
let low = head;
let fast = head.next;
while(low != fast){
	if(fast == null || fast.next == null){
		return false;
	}
	fast = fast.next.next;
	low = low.next;
}
return true
```


### 2. 找到循环链表的头结点
#### 哈希表Set
定义一个Set，跟1的思路一样
但是II一旦遇到在Set里面的节点，直接返回这个节点
其余情况返回null

#### 快慢指针
假设head到环开始的节点为x，环开始节点到相遇的节点为y，相遇点到环开始节点为z。
根据快指针移动的距离一直都是慢指针的两倍得出
2(x+y) = x + y + n(y+z)
x = (n - 1)(y+z)+z
x - z = (n - 1)(y + z)   n>=1
这个式子可以说明：head移动z的距离后，再到环开始节点的距离是环的（n - 1）倍

##### 问题：
> ***为啥快指针在慢指针没有走完一圈环就直接追上了呢？***
> 最坏的情况是：当慢指针刚到环开始节点，快指针只比慢指针快了1步，此时慢指针若走了一圈环的距离，快指针可以走两圈环的距离，中间一定会相遇。拿相对运动来说，这个最坏情况中，慢指针不动，快指针需要走（环长-1）才能与慢指针相遇，而其余情况慢指针走的距离都不会超过环长-1步，所以慢指针移动的距离是小于环长的
假设环长为s，fast距离slow s-1，他们的相对速度为1，那么需要s-1的时间fast才能追上slow，而这段时间slow走的距离也只有s-1，小于环长s

>***为啥n>=1***
>因为快指针需要只少走完1圈才能和慢指针相遇
>快指针不可能没走完1圈就能和慢指针相遇了
