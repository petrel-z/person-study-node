* @return {ListNode}

var reverseBetween = function(head, left, right) {

// 定义虚节点

let dumy = new ListNode();

dumy.next = head;

// 找到翻转部分的前一个节点

let pre = dumy;

for(let i = 0; i < left - 1; i++) {

pre = pre.next;

}

let r = head;

// 找到right对应节点

for(let i = 1; i < right; i++) {

r = r.next;

}

let p = r.next;//right右边那个节点，当成要翻转的链表的前节点

let cur = pre.next;//left对应节点

// 翻转left到right之间的节点

for(let i = left; i <= right; i++) {

let temp = cur.next;

cur.next = p;

p = cur;

cur = temp;

}

pre.next = p;

return dumy.next;

};

  

// 主要就是找到翻转链表前后要连接的节点

# 理论知识
### 一、链表的基本概念
1. **链表结构**  
   链表由节点组成，每个节点包含：
   - **值**（`val`）：存储数据。
   - **指针**（`next`）：指向下一个节点（最后一个节点的`next`为`null`）。

2. **常见链表类型**  
   - **单链表**：每个节点只有一个`next`指针。
   - **双链表**：每个节点有`prev`和`next`两个指针。
   - **循环链表**：尾节点的`next`指向头节点。


### 二、JavaScript 实现链表
用类或对象模拟链表节点：

```javascript
// 单链表节点
class ListNode {
  constructor(val, next) {
    this.val = val === undefined ? 0 : val;
    this.next = next === undefined ? null : next;
  }
}

// 创建链表: 1 -> 2 -> 3
const head = new ListNode(1);
head.next = new ListNode(2);
head.next.next = new ListNode(3);
```


### 三、核心操作与技巧
#### 1. **遍历链表**  
   使用循环或递归访问每个节点：
   ```javascript
   let current = head;
   while (current !== null) {
     console.log(current.val);
     current = current.next;
   }
   ```

#### 2. **双指针技巧**  
   - **快慢指针**：判断链表是否有环、找中间节点。
   - **间隔指针**：删除倒数第`n`个节点。

#### 3. **反转链表**  
   迭代法：
   ```javascript
   function reverseList(head) {
     let prev = null;
     let curr = head;
     while (curr) {
       const next = curr.next;
       curr.next = prev;
       prev = curr;
       curr = next;
     }
     return prev;
   }
   ```

#### 4. **合并链表**  
   合并两个有序链表：
   ```javascript
   function mergeTwoLists(l1, l2) {
     const dummy = new ListNode();
     let tail = dummy;
     while (l1 && l2) {
       if (l1.val < l2.val) {
         tail.next = l1;
         l1 = l1.next;
       } else {
         tail.next = l2;
         l2 = l2.next;
       }
       tail = tail.next;
     }
     tail.next = l1 || l2;
     return dummy.next;
   }
   ```

#### 5. **处理环**  
   判断链表是否有环：
   ```javascript
   function hasCycle(head) {
     let slow = head;
     let fast = head;
     while (fast && fast.next) {
       slow = slow.next;
       fast = fast.next.next;
       if (slow === fast) return true;
     }
     return false;
   }
   ```

### 五、注意事项
1. **边界条件**  
   - 链表为空（`head === null`）
   - 链表只有一个节点
   - 处理头节点和尾节点

2. **指针操作顺序**  
   反转链表时，先保存`next`指针再修改`prev`，避免丢失引用。

3. **虚拟头节点（Dummy Node）**  
   简化插入、删除头节点的逻辑：
   ```javascript
   const dummy = new ListNode();
   dummy.next = head;
   // 操作 dummy.next 而不是直接操作 head
   ```

4. **递归思维**  
   递归适合处理子问题（如反转链表、合并有序链表），但需注意栈溢出风险。
