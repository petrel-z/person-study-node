# 思路：递归实现归并排序
## 1. 将链表分成两部分
	1. 思路：快慢指针
	2. 注意：将左半边与右半边断开
	3. 参数：head
	4. 边界条件：head = null || head.next = null   返回[ head, null ]
```js
// 利用快慢指针二分链表

function splitList(head){

if(!head || !head.next){

return [head, null];

}

let pre = null;

let slow = head;

let fast = head;

while(fast && fast.next){

pre = slow;

slow = slow.next;

fast = fast.next.next;

}

pre.next = null;

return [head, slow];

}
```

## 2. 将两个链表合成一个链表
	1. while循环，一边比大小，一边合并
	2. 循环条件：l1 && l2 
	3. 参数：l1, l2
	4. 边界条件：l1 = null || l2 = null 返回l1 或者 l2
```js
// 按照顺序合并两个链表

function sortMerge(l1, l2){

let head = new ListNode();

let temp = head;

while(l1 && l2){

if(l1.val > l2.val){

temp.next = l2;

l2 = l2.next;

}else {

temp.next = l1;

l1 = l1.next;

}

temp = temp.next;

}

temp.next = l1 ? l1 : l2;

return head.next;

}
```

## 3. 递归实现
	1. 递归体：将一个链表分成两部分，分别将两部分再分，直到要分的链表为null或者只剩单个节点为止

```js
// 递归

function recursion(head){

if(!head || !head.next){

return head;

}

let [left , right] = splitList(head);

let l = recursion(left);

let r = recursion(right);

return sortMerge(l, r);

}
```



# 时间复杂度和空间复杂度的分析
## 时间复杂度
1. 递归分割链表 ： 遍历所有节点 O(n) * log n = O( n log n)
2. 递归排序合并两个链表：每层合并都需要遍历head链表的所有节点 ， O(n) * log n = O(n log n)
整体： 二者相加：O(n log n )

## 空间复杂度
分割链表、合并链表不需要额外的空间，只需要修改指针 O(1)
但是数组需要额外的开销

所以这道题整体的所有开销只有递归时 ，调用栈的开销
递归深度为log n  , 每一层递归调用会占用常数空间 ， 故递归栈 空间复杂度 为O(log n)
故空间复杂度为 O( log n )
