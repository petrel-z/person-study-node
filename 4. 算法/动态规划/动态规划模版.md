动态规划（Dynamic Programming, DP）是一种通过将复杂问题分解为重叠子问题，并利用子问题的解来高效求解原问题的方法。虽然没有万能模板，但可以总结出一套通用的解题框架，适用于大多数动态规划问题。
### 动态规划通用步骤
1. **定义状态**：确定 `dp[i]`（或 `dp[i][j]` 等）代表什么，通常是“以 `i` 为结尾的XXX的最优解”。
2. **确定状态转移方程**：找到 `dp[i]` 和 `dp[i-1]`（或其他前置状态）之间的关系。
3. **初始化**：设置边界条件（如 `dp[0]` 的值）。
4. **计算顺序**：根据依赖关系确定计算顺序（通常是从小到大）。
5. **返回结果**：根据问题要求，返回 `dp` 数组中的某个值（如 `dp[n]` 或最大值）。
### 一、一维 DP 模板（单数组）
适用于问题可转化为线性依赖关系的场景（如斐波那契数列、最长递增子序列）。

```javascript
function solveProblem(n) {
    // 1. 定义状态：dp[i] 表示前 i 个元素的解
    const dp = new Array(n + 1).fill(0);
    
    // 2. 初始化边界条件
    dp[0] = 0; // 根据具体问题设置
    if (n >= 1) dp[1] = 1; // 示例：斐波那契的 dp[1]
    
    // 3. 确定计算顺序（从小到大）
    for (let i = 2; i <= n; i++) {
        // 4. 状态转移方程（核心）
        dp[i] = dp[i - 1] + dp[i - 2]; // 示例：斐波那契数列
    }
    
    // 5. 返回结果
    return dp[n];
}
```

**示例场景**：  
- 斐波那契数列（`dp[i] = dp[i-1] + dp[i-2]`）  
- 爬楼梯问题（每次走1或2步，`dp[i] = dp[i-1] + dp[i-2]`）  


### 二、二维 DP 模板（矩阵）
适用于问题涉及两个维度的依赖关系（如二维网格、两个字符串的比较）。

```javascript
function solveProblem(m, n) {
    // 1. 定义状态：dp[i][j] 表示 i 行 j 列的解
    const dp = new Array(m + 1).fill(0).map(() => new Array(n + 1).fill(0));
    
    // 2. 初始化边界条件
    dp[0][0] = 0; // 示例：起点
    for (let i = 1; i <= m; i++) dp[i][0] = 1; // 第一列的解
    for (let j = 1; j <= n; j++) dp[0][j] = 1; // 第一行的解
    
    // 3. 计算顺序（按行或按列）
    for (let i = 1; i <= m; i++) {
        for (let j = 1; j <= n; j++) {
            // 4. 状态转移方程（核心）
            dp[i][j] = dp[i - 1][j] + dp[i][j - 1]; // 示例：网格路径数
        }
    }
    
    // 5. 返回结果
    return dp[m][n];
}
```

**示例场景**：  
- 网格路径问题（从左上角到右下角的路径数，`dp[i][j] = dp[i-1][j] + dp[i][j-1]`）  
- 最长公共子序列（`dp[i][j]` 表示两个字符串前 `i` 和 `j` 个字符的最长公共子序列长度）  


### 三、空间优化模板（滚动数组）
当状态转移只依赖前一行（或前几个状态）时，可通过滚动数组减少空间复杂度（如从 `O(n^2)` 优化为 `O(n)`）。

```javascript
function solveProblem(n) {
    // 优化：用两个变量存储前两个状态（替代整个数组）
    if (n === 0) return 0;
    if (n === 1) return 1;
    
    let prevPrev = 0; // 对应 dp[i-2]
    let prev = 1;     // 对应 dp[i-1]
    let current;
    
    for (let i = 2; i <= n; i++) {
        current = prev + prevPrev; // 状态转移
        // 滚动更新
        prevPrev = prev;
        prev = current;
    }
    
    return current;
}
```

**示例场景**：  
- 斐波那契数列（从 `O(n)` 空间优化为 `O(1)`）  
- 打家劫舍问题（只依赖前两个房间的状态）  


### 四、动态规划解题关键
1. **状态定义是核心**：  
   状态定义需要准确描述问题的子结构，例如“`dp[i]` 表示以第 `i` 个元素结尾的最大和”比“`dp[i]` 表示前 `i` 个元素的最大和”更易推导出转移方程。

2. **状态转移方程要明确**：  
   思考“当前状态如何通过之前的状态计算得出”，避免遗漏边界情况（如空数组、单元素）。

3. **初始化要准确**：  
   边界条件是递归的终点，例如斐波那契数列中 `dp[0] = 0`、`dp[1] = 1`。

4. **多练习总结类型**：  
   动态规划问题类型有限（如背包问题、子序列问题、区间问题等），熟悉每种类型的状态定义和转移规律可快速解题。


### 常见动态规划问题类型
- 背包问题（0-1背包、完全背包）  
- 子序列问题（最长递增子序列、最长公共子序列）  
- 区间DP（石子合并、回文子串）  
- 计数类DP（路径数、组合数）  
- 博弈类DP（预测赢家、石子游戏）  

掌握上述模板和思路后，可通过具体问题调整状态定义和转移方程，逐步形成动态规划思维。
