字符串、动态规划

要求：有两个字符串，在一个字符串中找到，另一个字符串在前一个字符串中的最大公共子序列

输入：text1 = "abcde", text2 = "ace" 
输出：3  
解释：最长公共子序列是 "ace" ，它的长度为 3 。


分析问题：
1. text2字符串中的字符在text1中出现的顺序必须一致，出现的位置不限制

思考：
1. 如何保证text2中的字符在text1中出现的顺序保持一致
2. 如何检索在text1中出现的text2的字符


思路：
1. 遍历两个字符串
2. 从text2中依次拿出一个字符串，在text1中比对
3. 如果在text1中出现，继续检查text2中下一个字符
4. 最后text1最多遍历一遍

以上的思路是错误的
因为没有考虑到：当text2前面的字符在text1没有出现，就直接返回结果了，但是text2后面的字符就被忽略了
text1 = "bl"，text2 = "yby"

采用动态规划分析：
1. 如何定义dp[i][j]数组，每个元素代表什么
	1. dp[i][j]代表 text1的前i个字符和text2前j个字符的最长公共子序列
2. dp[i] 和 dp[i -  1] 的关系是什么
	1. text1[i - 1] 和text2[j - 1] 字符相等：`dp[i][j] = dp[i - 1][j - 1] + 1`
	2. 字符不相等：`dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1])
`
3. 边界初始化条件是什么: `dp[i][j] = 0 ` 此时没有公共子序列


```js
/**
 * @param {string} text1
 * @param {string} text2
 * @return {number}
 */
var longestCommonSubsequence = function(text1, text2) {
    let m = text1.length;
    let n = text2.length;
    let dp = new Array(m+1).fill(0).map(() => new Array(n+1).fill(0));
    for(let i = 1; i <= m; i++){
        let a = text1[i-1];
        for(let j = 1; j <= n; j++){
            let b = text2[j-1];
            if(a === b){
                dp[i][j] = dp[i-1][j-1] + 1;
            }else{
                dp[i][j] = Math.max(dp[i-1][j], dp[i][j-1]);
            }
        }
    }
    return dp[m][n];
};
```
