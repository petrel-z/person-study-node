# 配置@
### **一、配置 `@` 别名（Next.js 13+ App Router）**

Next.js 13+ 推荐使用 `app` 目录结构，配置 `@` 需修改 **`next.config.js`** 和 **`tsconfig.json`**（TypeScript 项目）。

#### **1. 修改 `next.config.js`**

在项目根目录的 `next.config.js` 中，通过 `webpack` 配置别名：

```javascript
/** @type {import('next').NextConfig} */
const nextConfig = {
  reactStrictMode: true,
  // 配置 Webpack 别名
  webpack: (config) => {
    config.resolve.alias = {
      ...config.resolve.alias,
      // 将 @ 指向 src 目录（如果没有 src 目录，可指向项目根目录）
      '@': path.resolve(__dirname, 'src'),
    };
    return config;
  },
};

module.exports = nextConfig;
```

#### **2. 修改 `tsconfig.json`（TypeScript 项目）**

为了让 TypeScript 识别 `@` 别名（避免编译报错），在 `tsconfig.json` 中添加 `paths` 配置：

json

```json
{
  "compilerOptions": {
    "target": "es5",
    "lib": ["dom", "dom.iterable", "esnext"],
    "allowJs": true,
    "skipLibCheck": true,
    "strict": true,
    "forceConsistentCasingInFileNames": true,
    "noEmit": true,
    "esModuleInterop": true,
    "module": "esnext",
    "moduleResolution": "bundler",
    "resolveJsonModule": true,
    "isolatedModules": true,
    "jsx": "preserve",
    "incremental": true,
    "plugins": [
      {
        "name": "next"
      }
    ],
    // 关键：配置路径别名
    "baseUrl": ".", // 基础路径（项目根目录）
    "paths": {
      "@/*": ["src/*"] // @ 对应 src 目录下的所有文件
    }
  },
  "include": ["next-env.d.ts", "**/*.ts", "**/*.tsx", ".next/types/**/*.ts"],
  "exclude": ["node_modules"]
}
```
