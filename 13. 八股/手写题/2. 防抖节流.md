防抖函数：
在一段时间过后才会执行任务，在此期间，如果重新触发了事件，则重新计算时间
存放一个定时器，让时间触发时，刷新定时器，

节流函数：
在一段时间内，只执行一次任务



```js
function debounce(fn, wait){
	let timer = null;
	return function (...args) {
		if (timer) {
			clearTimeOut(timer);
		}
		timer = setTimeout(() => {
			fn.apply(this, args);
			timer = null;
		}, wait)	
	}
}

```

节流
```js
function thiron(fn, wait) {
	let last = 0;
	return function (...args) {
		let now = new Date();
		if(now - last >= wait) {
			fn.apply(this, args);
			last = now;
		}
	}
}

```
