instanceof的原理就是原型和原型链
它的作用是：
检查构造函数的prototype是否出现在实例对象的原型上

思路：
1. 获取对象的原型
2. 获取构造函数的原型
3. 循环比较对象的原型是否等于构造函数的原型

```js
function myInstanceof(left, right) {
	let proto = Object.getPrototypeOf(left);
	let prototype = right.prototype;
	while(true) {
		if(!proto) {
			return false;
		}
		if(proto === prototype) {
			return true;
		}
		proto = Object.getPrototypeOf(proto);
	}
}
```
