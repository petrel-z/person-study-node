# 本周学习总结&反思:

总结：

1. 我们做项目时局限于某个功能的实现以及联调时只考虑某个接口能否调成功，没有考虑某个东西是否合理以及对用户友好，以及接口是否还会出现其他报错。
    
2. 输出知识的时候还是很困难
    
3. 在碰到一个陌生的技术的实现时，不要只局限于问ai，可以用搜索引擎多艘别人总结的文章或者官方文档。
    
4. 考核别人js的时候准备的不够充分，有很多自己也说不上来，可见基础的薄弱性。
    

反思：

1.  以产品的思维做项目，拿出最优解，多站在用户角度考虑业务逻辑完整且是否符合逻辑 
    
2. 项目的测试做的太少了，尤其是完整的流程都没完整的测试，走不通逻辑 
    
3. 在开发前应该想好需求，对好字段，整体把握项目，一切都想明白了再开始开发 
    
4. 团队合作中要及时、有效去沟通，不要不吭声，尤其是遇见问题的时候
