围绕「**一年后进入大厂实习（前端方向）**」这个目标，来做一个**完整、有闭环的复盘示例**。
## 🎯 一、目标设定（SMART 原则）

| 维度                   | 说明                                                                    |
| :------------------- | :-------------------------------------------------------------------- |
| **S（Specific）明确**    | 进入大厂实习，从事前端开发岗位                                                       |
| **M（Measurable）可量化** | 目标公司：阿里、字节、美团等；岗位要求：React/Vue + 算法基础 + 项目经验，开源项目，个人可见的产出（博客输出，github） |
| **A（Attainable）可实现** | 当前已掌握 HTML/CSS/JS，react、vue基础良好，有时间可系统学习提升                            |
| **R（Relevant）相关性**   | 与本人专业、职业目标高度相关                                                        |
| **T（Time-based）时限性** | 目标时间：6个月，明年四月份拿到offer                                                 |

✅ **一句话目标**：

> 通过培养个人特色化，并半年内通过系统学习 + 项目积累 + 面试准备，成功进入大厂实习。

---

## 🧭 二、回顾过程（5W1H）

| 维度        | 反思问题     | 当前状况                             |
| :-------- | :------- | :------------------------------- |
| **What**  | 做了哪些努力？  | 学完了Vue基础、做了1个慢跑小程序项目、刷了部分面试高频算法题 |
| **Why**   | 为什么这样安排？ | 想先把框架学熟                          |
| **Who**   | 谁参与或指导？  | 自己 +家族七期全体成员                     |
| **When**  | 时间规划如何？  | 前三个月效率高，后期拖延严重                   |
| **Where** | 学习环境如何？  | 在宿舍学习，容易分心                       |
| **How**   | 学习方法？    | 看视频+模仿项目，缺乏系统复盘                  |

📌 初步结论：努力方向没问题，但执行不稳定、计划分散、复盘缺失。

---

## 🔍 三、原因分析（4M1E）

| 维度                 | 问题             | 影响     | 改进措施           |
| :----------------- | :------------- | :----- | :------------- |
| **Man（人）**         | 自制力差，拖延；缺少同伴监督 | 学习节奏断裂 | 建立学习打卡群，互相监督   |
| **Machine（机）**     | 电脑配置老旧，编译卡顿    | 降低效率   | 升级设备或使用在线编译环境  |
| **Material（料）**    | 学习资料来源杂，质量参差   | 学习路径混乱 | 整理系统学习路线，固定资料源 |
| **Method（法）**      | 没有计划表和复盘机制     | 学习无反馈  | 使用“周计划 + 周复盘”  |
| **Environment（环）** | 宿舍嘈杂、手机干扰多     | 学习专注度低 | 改去图书馆/学习室学习    |

📌 找到关键瓶颈：**方法 + 环境（手机） + 自控力**。

---

## 💡 四、总结经验（提炼规律）

### 成功点：
    
- 愿意持续学习，有项目积累意识；
    
- 有一定技术兴趣驱动力。
    

### 不足点：

- 缺少长期节奏与反馈机制；
    
- 复盘意识弱，错误重复；
    
- 缺少展示成果的“作品集意识”。
    

### 经验沉淀：

1. **计划 ≠ 执行**，需要量化 + 检查点；
    
2. **学习要留痕**（笔记、项目、日志）；
    
3. **周期性复盘**，调整方向及时；
    
4. **从做中学**：实践比听课更重要。

## 🚀 五、制定新行动计划（5W1H 行动闭环）

| 维度        | 内容                       |
| :-------- | :----------------------- |
| **What**  | 制定“12个月大厂实习计划”           |

## 🔁 六、验证与迭代

三个月后进行一次“中期复盘”，发现：

- 已完成技术学习阶段；
    
- 项目上线一个，但算法题仅完成一半；
    
- 每周复盘有效，学习更自觉；
    
- 仍需优化时间管理。
    

**调整计划：**

- 每晚22点前必须完成当日学习；
    
- 算法题设“每日一题”强制打卡；
    
- 月底邀请同伴互评项目。
    

📌 这就是“**闭环的关键：执行—反馈—优化—再执行**”。
