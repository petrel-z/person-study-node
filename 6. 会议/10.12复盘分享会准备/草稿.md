# 复盘的意义
1. 解决某些问题（更好做一件事）
2. 保优废差
3. 积累经验，不断成长、精进，提升能力
4. 将做过的事情留痕，可用在工作汇报中
5. 看清未来，纠正成长轨迹


# 如何有效复盘，找到真正的原因
找到事情发展规律

1. 观察
	1. 想清楚为什么做？
	2. 想要做成什么结果
	3. 目标是否可量化、具体
2. 反思：水平和垂直
	1. 工具：mece原则、逻辑树、思维导图、鱼骨图
	2. 4M1E（人机物法环）：考试没考好
		1. 人员man：跟我有关系的人对我的影响（老师讲的不好）
		2. 机器machine：辅助工具（教材不够好
		3. 物料material：材料（考试难度大
		4. 方法method：学习方法、技巧 
		5. 环境environment：学习环境、生活环境
	3. 根据反思，大胆假设，小心求证
3. 行动
	1. 5W1H
		1. what:  做什么（行动）
		2. why:  为什么做（目的）
		3. who:  跟谁做
		4. when:  什么时候做（具体时间）
		5. where:  在哪做（具体地点）
		6. how：如何做（方法、技巧）

简单重复1万次，不如有效重复一次。
进步小不可怕，比没有进度强
将小的进步进行循环迭代


# 复盘方法

复盘五部曲：
1. 回顾目标：查看自己定制的目标
2. 对比结果：将完成结果和目标进行对比，哪些完成，哪些未完成
3. 还原过程：在完成某一个目标时，记录下来经历的过程，做了哪些动作，产生了什么结果和影响
	1. 利用积极影响，规避消极影响
	2. 事件的受益方是谁、利益受损方
	3. 事件传递的价值观
4. 分析原因：针对目标完成度和过程的记录，分析未完成目标时，过程中的哪一个环节出了问题
5. 总结经验：对于好的行为，记录下来，下次遇到同样的情况复用即可；对于不好的行为，思考如何改进才有利于实现目标
6. 迭代行动


# 如何目标管理
SMART：
S: Specific 明确的
M: Messurable 可衡量的
A: Attainable 可实现的
R: Relevant 现实的
T: Time-based 有时限的

eg： 目标：一个月内掌握300单词
