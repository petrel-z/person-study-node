## 背景：
flex和grid出现之前，是float来做一些简单的布局，如两列布局，圣杯布局等
但是float做布局有一些痛点：
1. 父盒子高度塌陷
由于float元素会脱离正常的文档流，就会它不会参与计算父盒子的高度，因此我们就需要手动清除浮动：
```css
.parent::after {
  content: "";
  display: block;
  clear: both;
} // 给父盒子的伪元素清除浮动
```
因为float元素会影响之后的元素，让它后面的元素围绕着它排列，因此清除浮动的目的是让该元素不能和float元素在同一行，必须在float的下面，这样就可以让父元素的伪元素撑开整个父盒子，从而解决父盒子高度塌陷的问题
2. 无法做到垂直或水平居中
