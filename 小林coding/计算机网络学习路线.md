# 计算机网络学习路线

> 目标：用“学 + 用”的方式学习计算机网络。不是只看完文章，而是做到能讲出来、能画出来、能抓包看到、能用在问题排查里。

参考资料：

- 小林 Coding《图解网络》：https://xiaolincoding.com/network/
- 小林 Coding《计算机网络怎么学？》：https://xiaolincoding.com/network/5_learn/learn_network.html

## 一、学习总原则

我的基础比较薄弱，所以不要一开始就按照“物理层、数据链路层、网络层、传输层、应用层”硬背。

更适合我的方式是：围绕真实问题来学。

例如：

- 为什么浏览器输入网址后能打开网页？
- 为什么需要 DNS？
- 为什么 TCP 要三次握手？
- 为什么 HTTPS 比 HTTP 安全？
- 为什么网络慢、请求超时、连接断开？
- ping 到底在测什么？

每学一个知识点，都必须走完下面这个闭环：

1. **学**：看一小节内容，只解决一个问题。
2. **画**：画流程图，把过程画出来。
3. **抓**：尽量用命令、浏览器开发者工具或 Wireshark 看到真实现象。
4. **讲**：用自己的话讲一遍，讲不出来就说明还没有真的理解。

## 二、整体学习路线

### 第 1 阶段：建立全局地图

学习内容：

- TCP/IP 网络模型
- OSI 七层模型和 TCP/IP 四层模型的关系
- 每一层分别解决什么问题
- 数据是如何一层层封装和解封装的

实践任务：

- 画出“浏览器访问网站”的大致链路：
  - 浏览器
  - HTTP / HTTPS
  - TCP
  - IP
  - 网卡
  - 路由器
  - 服务器

重难点：

- 重点：★★★★★
- 难点：不要死背分层名字，要理解“每层解决什么问题”。

我需要掌握到什么程度：

- 能说出应用层、传输层、网络层、网络接口层分别负责什么。
- 能解释为什么网络要分层。
- 能把一次网页访问放进这个模型里。

### 第 2 阶段：从 ping 入门网络层

学习内容：

- IP 地址
- 子网掩码
- 默认网关
- 路由
- ICMP
- ping 的基本原理
- 127.0.0.1、localhost、本机 IP 的区别

实践任务：

```bash
ping xiaolincoding.com
ping 127.0.0.1
nslookup xiaolincoding.com
traceroute xiaolincoding.com
```

如果是 Windows，可以把 `traceroute` 换成：

```bash
tracert xiaolincoding.com
```

重难点：

- 重点：★★★★☆
- 难点：IP、子网、网关、路由表之间的关系。

我需要掌握到什么程度：

- 知道 ping 用的是 ICMP。
- 知道 ping 通不等于服务一定可用。
- 能解释“同一个局域网”和“跨网段访问”的区别。

### 第 3 阶段：输入网址到网页显示

学习内容：

- 输入 URL 后发生了什么
- DNS 解析
- TCP 连接
- TLS / HTTPS 握手
- HTTP 请求和响应
- 浏览器拿到资源后的基本处理

实践任务：

- 打开浏览器开发者工具。
- 进入 Network 面板。
- 访问 https://xiaolincoding.com/network/
- 观察：
  - 请求 URL
  - 状态码
  - 请求头
  - 响应头
  - 资源加载时间
  - 是否走了缓存

重难点：

- 重点：★★★★★
- 难点：把 DNS、TCP、HTTPS、HTTP 串成一条完整链路。

我需要掌握到什么程度：

- 能完整讲出“输入网址到页面显示”的主流程。
- 能知道每一步分别属于哪一层。
- 面试时能按顺序回答，而不是碎片化背知识点。

### 第 4 阶段：HTTP / HTTPS

学习内容：

- HTTP 请求方法：GET、POST、PUT、DELETE
- 常见状态码：200、301、302、304、400、401、403、404、500、502、503
- Header
- Cookie
- Session
- 缓存
- 长连接
- HTTP/1.1
- HTTP/2
- HTTP/3
- HTTPS、TLS、证书、加密

实践任务：

```bash
curl -v https://xiaolincoding.com/network/
```

观察：

- 请求是怎么发出去的
- 响应状态码是什么
- 响应头里有哪些字段
- 是否有缓存相关字段
- 是否有 HTTPS / TLS 相关信息

重难点：

- 重点：★★★★★
- 难点：HTTPS 握手、证书验证、HTTP 缓存、HTTP/2 多路复用。

我需要掌握到什么程度：

- 能看懂浏览器 Network 面板里的主要字段。
- 能解释 GET 和 POST 的常见区别。
- 能解释 HTTPS 大概如何保证安全。
- 能说清楚常见状态码的含义。

### 第 5 阶段：TCP 核心

学习内容：

- TCP 和 UDP 的区别
- TCP 三次握手
- TCP 四次挥手
- 序列号
- 确认号
- ACK
- 超时重传
- 快速重传
- 滑动窗口
- 流量控制
- 拥塞控制
- TIME_WAIT
- CLOSE_WAIT

实践任务：

- 用 Wireshark 抓一次网页访问。
- 过滤 `tcp`。
- 找到三次握手：
  - SYN
  - SYN + ACK
  - ACK
- 观察客户端和服务端端口。
- 观察序列号和确认号。

重难点：

- 重点：★★★★★
- 难点：滑动窗口、拥塞控制、TIME_WAIT、序列号和确认号变化。

我需要掌握到什么程度：

- 能画出三次握手和四次挥手。
- 能解释为什么是三次握手，不是两次。
- 能解释为什么会有 TIME_WAIT。
- 能解释 TCP 为什么可靠。
- 能初步看懂 Wireshark 中的 TCP 包。

### 第 6 阶段：UDP 与 QUIC

学习内容：

- UDP 的特点
- UDP 为什么快
- UDP 为什么不保证可靠
- DNS 为什么常用 UDP
- 视频、游戏为什么常见 UDP
- QUIC / HTTP/3 为什么基于 UDP

实践任务：

- 对比 TCP 和 UDP 的使用场景。
- 思考：
  - 文件传输为什么更适合 TCP？
  - 直播、游戏为什么可能更适合 UDP？
  - HTTP/3 为什么不直接继续用 TCP？

重难点：

- 重点：★★★☆☆
- 难点：不要简单理解成“UDP 一定会丢包”，而是理解“UDP 协议本身不保证可靠”。

我需要掌握到什么程度：

- 能说清楚 TCP 和 UDP 的核心区别。
- 能结合场景说明为什么选择 TCP 或 UDP。
- 对 QUIC 有基本印象即可，前期不需要深入源码和协议细节。

### 第 7 阶段：Linux 网络与排障

学习内容：

- socket
- listen
- accept
- 端口
- 连接队列
- 网卡收包
- 内核协议栈
- 常见网络排查命令

实践任务：

```bash
ss -tunlp
lsof -i
netstat -an
tcpdump
```

重难点：

- 重点：★★★★☆
- 难点：这部分偏工程实践，建议在 TCP 基础打好后再学。

我需要掌握到什么程度：

- 能查看本机有哪些端口在监听。
- 能判断一个服务是否启动。
- 能初步分析连接失败、端口不通、请求超时等问题。

## 四、每天怎么学

每天 60 到 90 分钟即可，关键是稳定。

推荐节奏：

1. 20 分钟：读一个小节。
2. 20 分钟：画流程图或写自己的理解。
3. 20 分钟：做实验，比如 `ping`、`curl`、浏览器 Network、Wireshark。
4. 10 分钟：回答 3 个问题。
5. 5 分钟：记录今天最不懂的一个点。

每天至少要留下一个输出物：

- 一张流程图
- 一段自己的解释
- 一次命令结果
- 一张抓包截图
- 一个错题记录

不要只看文章。只看文章很容易产生“我好像懂了”的错觉。

## 五、6 周学习计划

### 第 1 周：网络地图 + ping

目标：

- 建立网络分层概念。
- 理解 IP、网关、路由、ICMP。
- 能说清楚 ping 在做什么。

输出：

- 一张 TCP/IP 四层模型图。
- 一份 ping 实验记录。

### 第 2 周：URL 到网页显示 + DNS

目标：

- 能完整讲出输入网址到页面显示的流程。
- 理解 DNS 解析在其中的位置。

输出：

- 一张“输入 URL 到页面显示”的流程图。
- 一次浏览器 Network 面板观察记录。

### 第 3 周：HTTP

目标：

- 掌握请求方法、状态码、Header、缓存、长连接。
- 能看懂一个 HTTP 请求和响应。

输出：

- 常见状态码表。
- 一次 `curl -v` 分析记录。

### 第 4 周：HTTPS

目标：

- 理解 TLS 握手。
- 理解证书、对称加密、非对称加密的大概作用。

输出：

- 一张 HTTPS 握手流程图。
- 用自己的话解释“HTTPS 为什么安全”。

### 第 5 周：TCP 基础

目标：

- 掌握三次握手、四次挥手、可靠传输、TIME_WAIT。

输出：

- 三次握手图。
- 四次挥手图。
- 一次 Wireshark 抓包记录。

### 第 6 周：TCP 进阶 + 排障

目标：

- 理解滑动窗口、流量控制、拥塞控制、重传。
- 能进行基础网络问题排查。

输出：

- TCP 可靠传输总结。
- 常见网络故障排查清单。

## 六、向老师提问的方式

以后可以这样问：

- “我看完 TCP 三次握手了，你考我一下。”
- “我不懂为什么是三次握手，不是两次。”
- “这是我的理解，你帮我纠错。”
- “我抓包看到这些字段，帮我解释。”
- “这个面试题我不会答，带我拆。”
- “我今天学了这些，你帮我判断有没有理解偏。”

我提问时最好带上：

- 我看的章节
- 我自己的理解
- 我不懂的点
- 命令输出或抓包截图

## 七、第一课任务

今天先不要急着看 TCP。

第一课只做一件事：搞懂“网络分层”。

任务：

1. 看小林 Coding《TCP/IP 网络模型有哪几层？》
2. 用自己的话回答：
   - 应用层解决什么问题？
   - 传输层解决什么问题？
   - 网络层解决什么问题？
   - 网络接口层解决什么问题？
3. 画一条链路：
   - 浏览器
   - HTTP
   - TCP
   - IP
   - 网卡
   - 服务器

学完后，把自己的理解发给老师。哪怕很乱也可以，重点是先输出，再纠正。

## 八、学习时的提醒

- 不要追求一天学很多。
- 不要只收藏资料。
- 不要只看不练。
- 不要怕问很基础的问题。
- 每个知识点都要尽量和真实现象连接起来。
- 能抓包看到的，就不要只停留在文字解释。
- 能用自己的话讲出来，才算真正开始理解。
