     - 💉 `&`合并类型：相当于Object.assign  
     - ☢️ `ComputedRef`：说明roles是计算属性（需用computed()包裹）

3. **写法翻译机**：  
   - 把看不懂的Vue3写法转成Vue2选项式（双向对照）：  
     ```vue
     // 组合式地狱 → 选项式救星
     const { data } = await useFetch('/api') 
     // 翻译成： 
     export default { 
       async created() { 
         this.data = (await axios.get('/api')).data 
       } 
     }
     ```
