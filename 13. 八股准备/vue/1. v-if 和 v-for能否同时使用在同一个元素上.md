# 考察：
1. 指令的优先级顺序，vue2和vue3优先级不同
2. 多余的dom渲染引起的性能问题
3. 指令明确的使用场景，v-if 负责条件渲染， v-for 负责渲染列表项
4. 数据和视图分离的思想，视图只负责展示数据，数据筛选应放在逻辑层处理

# vue2中
优先级：v-for 大于 v-if 
因此在同一个元素同时使用v-if和v-for时，会先渲染所有的列表项，再去筛掉不符合条件的列表项，造成多余的遍历和dom渲染，消耗性能

# vue3中
优先级：v-if 大于 v-for 
因此在同一个元素中同时使用 v-if 和 v-for 时，列表项变量还未定义，使得 v-if 中的属性还未定义，导致报错


# 解决方案：
1. 将筛选逻辑放在逻辑层，使得视图只负责渲染处理过的数据
2. 使用template模版：
	1. 外层用template模版进行 v-if 条件判断；内层进行 v-for 渲染数据项
	2. 外层用template模版进行 v-for 渲染；内层使用 v-if 判断单个列表项
3. 使用 v-show 代替 v-if：因为 v-show 只是改变dow的display属性，而不会新增或删除dom元素，性能比 v-if 好，但是 v-show 会渲染所有列表项，当数据量大时比较耗费性能
