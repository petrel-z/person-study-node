- 路由守卫怎么做？ <br/> 说法：在路由前置守卫里恢复登录态，判断 requiresAuth 与 guest 元信息，未登录跳转登录页，已登录访问游客页跳转首页。 router/index.ts
- 登录态如何在刷新后恢复？ <br/> 说法：Pinia 存用户信息与 token，同时写入 localStorage；应用启动或路由切换时调用恢复方法从本地读取。 auth.ts
- Token 过期怎么处理？ <br/> 说法：请求拦截器中检测过期，刷新 token；刷新失败时统一登出并跳转登录页。 request.ts
- 组件拆分与异步加载怎么做？ <br/> 说法：HeaderBar、OJCard、LeaderboardCard 使用 defineAsyncComponent 异步加载以减轻首屏压力。 HomeView.vue
- 背景轮播如何优化首屏性能？ <br/> 说法：首屏只加载第一张，其他图 idle 时间加载，并用 decoding="async" 与 fetchpriority 优化。 BackgroundCarousel.vue
- 构建优化和产物压缩如何做？ <br/> 说法：Vite 构建时开启 gzip/brotli 压缩、图片压缩、分包策略与资源命名，减少体积与提升缓存命中。 vite.config.ts
