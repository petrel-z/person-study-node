思路 ：
1. 创建一个空对象
2. 将该对象的_proto_指向构造函数的prototype
3. 将构造函数的this指向该实例对象，并传递参数
4. 返回该构造函数的返回值

```js
function myNew(fn, ...args) {
	let obj = {};
	Object.setPrototypeOf(obj, fn.prototype);
	let res = fn.apply(obj, args);
	return res instanceof Object ? res : obj;
}
```

最后的返回值判断原因：
fn.apply(obj, args); 的结果是fn执行后的结果，也就是构造函数的返回结果
如果构造函数没有返回值，则res为undefined，那么就需要防止new 之后return为undefined
