

# Python 最主流、最常用的**框架大全**（按用途分类，新手一看就懂）
我给你整理**最实用、工作必用、面试常问**的 Python 框架，分 5 大场景，不啰嗦、直接能用。

---

## 一、Web 开发框架（做网站、接口、后端）
### 1. **Django**（全能型、大厂最常用）
- 特点：**大而全**，自带数据库、后台、认证、安全
- 适合：快速开发企业级网站、管理系统、电商
- 代表：Instagram、 Pinterest、知乎早期

### 2. **Flask**（轻量小巧、自由度高）
- 特点：极简、灵活、想装什么装什么
- 适合：小网站、API 接口、个人项目

### 3. **FastAPI**（现代最快、专做 API）
- 特点：**速度极快**、自动生成接口文档
- 适合：后端接口、微服务、AI 模型部署
- 现在最火、AI 时代必学

---

## 二、爬虫框架（批量爬数据、自动化）
### 1. **Scrapy**（爬虫第一框架）
- 特点：高性能、并发、去重、分布式
- 适合：批量爬大量数据、企业爬虫

### 2. **Playwright**（动态爬虫神器）
- 特点：模拟浏览器、爬 JS 渲染网站、国外网站神器

### 3. **Selenium**（老牌自动化爬虫/测试）

---

### 1. **Pandas**（数据处理必备）
### 2. **NumPy**（数值计算）
### 3. **Matplotlib**（画图可视化）
### 4. **Scikit-learn**（机器学习）
### 5. **PyTorch**（深度学习最火框架）
### 6. **TensorFlow / Keras**（谷歌深度学习）

## 四、自动化测试框架
### 1. **Pytest**（Python 最主流测试框架）
### 2. **Selenium**（Web 自动化测试）
### 3. **Playwright**（新一代自动化测试）

### 1. **aiohttp**（异步爬虫、接口）

# 🔥 最简单学习路线（新手直接照这个学）
1. **Web 后端** → FastAPI / Flask
2. **爬虫** → Scrapy + Playwright
3. **数据分析/AI** → Pandas + PyTorch
