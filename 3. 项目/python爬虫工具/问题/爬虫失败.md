我做的工作和结论                                                                             
                                                                                               
  问题诊断
                                                                                               
  爬虫无法访问 glm.cn、www.glm.cn、minimax.com 等域名，但 qwen.ai、www.trae.ai、www.moonshot.cn
   可以正常访问。                                                                              
                                                                                               
  测试过程        

  1. Python requests 通过代理访问失败：glm.cn 返回 SSL 错误 SSL_ERROR_SYSCALL
  2. curl 命令行直接访问也失败：同样的 SSL 错误
  3. 对比测试发现：                                                                            
    - qwen.ai → 200 正常
    - www.trae.ai → 200 正常                                                                   
    - www.moonshot.cn → 200 正常
    - glm.cn、minimax.com → 返回码 000（连接失败）                                             
  
  结论                                                                                         
                  
  问题不是代码问题，而是这些域名（glm.cn、minimax.com                                          
  等）在你当前网络环境下无法通过代理正常访问，可能是：
  - 这些域名被代理屏蔽                                                                         
  - 代理对某些域名有访问限制
  - 这些站点对代理 IP 不友好

  qwen.ai 和 trae.ai 可以正常工作，所以代码本身没问题。                                        
  
  代码修改                                                                                     
                  
  我重写了 base.py，改用 subprocess 调用系统 curl 来替代 Python requests，以消除 Python        
  层面的代理配置问题。但根本原因是网络层面的，这部分无法通过代码修复。
