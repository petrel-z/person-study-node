# 项目背景：
大学新生刚入学时，常常会面临对学校不了解的问题，以及老生不知道学校信息，从而带来各种麻烦或者信息差，如以下场景。
	1. 新生不了解学校内寝室楼或者教学楼在哪里，或者不知道学校的各种信息，如校历、校史、通知等。
	2. 学生不了解学院相关介绍或者学院的培养方案、学科建设、奖学金要求、资助要求等学院相关的具体信息
	3. 新生在入学前不知道要做哪些准备等等

# 项目介绍：
该项目是一款汇总河南科技学院各种信息的平台，功能全面且便捷，帮助学生减少信息差，为学习和生活带来便利，适应广大科院学生群体。

# 项目技术栈：
wxml+javascript+uniapp+fuse.js

# 功能实现与技术方案：

## 数据加载：
1. oss云存储json文件，好处：
	1. 减少项目体积
	2. json文件改变不用重新发版
2. 请求重试机制，当遇到网络问题或服务器压力大，请求失败后，请求进行重试，超过特定次数就不再重试
3. 防缓存机制：请求的接口不缓存在本地，每次都重新请求接口获取最新数据

	缓存机制：新增一个获取json文件版本号的接口，查询该文件是否更改

## 全局搜索：
1. 三层架构设计，保证系统健壮性：
	表现层：页面展示
	调用管理层：调用服务层、模块间通讯
	服务层：数据管理、搜索算法
2. 配置 fuse.js 库的搜索配置，采用评分算法，实现全局模糊搜索以及权重匹配
3. 搜索结果排序策略：按照匹配权重计算后的得分排序
4. 懒初始化、条件渲染、scroll-view实现虚拟滚动等提高性能
5. 使用promise.all实现异步并发请求，节省时间


## 地图功能：
1. 调用腾讯地图接口api，实现前向差分解压坐标和计算实时距离/时间/速度等数据处理，实现路线规划
2. 利用地图对象的addGroundOverlay方法实现自定义地图底图
3. 本地配置地图默认配置，实现数据获取降级处理
4. 缓存地图数据，一次请求即可
5. 获取用户位置权限校验，地图边界处理
6. 地图标记点动态渲染、分类渲染


# 简历书写
- 架构设计与性能优化 ：采用分包加载（Subpackages） 策略重构项目结构，配合 按需注入（Lazy Loading）机制，显著降低首屏代码体积，提升启动速度。
- 地图核心功能开发 ：基于 腾讯地图 SDK 实现校园地图导览，开发了自定义图层叠加、路径规划（步行/骑行/驾车）、POI 点位聚合与边界限制功能。
- 高性能搜索模块 ：集成 Fuse.js 实现纯前端 模糊搜索引擎 ，通过加权算法和自定义评分机制，实现了毫秒级的本地数据检索，减少服务器压力。
- 动态配置系统 ：设计了基于 CDN 的 远程动态配置方案 ，利用 CommonJS 模块缓存更新机制（ updateModuleExports ），实现了无需发版即可热更新地图数据和配置项。
- 高可用网络层封装 ：封装统一的 request 请求库，实现了 请求/响应拦截器 、Token 自动注入、以及 指数退避算法 的自动重试机制（3次重试），提升了弱网环境下的用户体验。
