
### 为什么cli用go而不是node

因为go可以直接打包成可执行文件，直接运行，并且体积小、启动速度快
而node也可以打包，但是打包后的文件需要node环境才能执行，并且启动速度不快


### 报错：
VM15 sandbox_bundle:2 Unable to load preload script: /Users/petrel/project/desktop-pet/dist-main/src/preload/control.js

|   |   |   |   |
|---|---|---|---|
||executeSandboxedPreloadScripts|@|VM15 sandbox_bundle:2|
||(anonymous)|@|VM15 sandbox_bundle:2|
||(anonymous)|@|VM15 sandbox_bundle:2|
||___electron_webpack_init__|@|VM15 sandbox_bundle:2|
||(anonymous)|@|VM15 sandbox_bundle:2|


解决：
因为在 Electron 22.0.0 版本当中，sandbox  成为了默认选项，在开启了沙盒环境的情况下，preload 脚本默认被禁用（但实际体验还是能用？），因此会出现 “Unable to load preload script” 的报错，得通过设置 sandbox: false 将其禁用
