# 课表小程序功能与设计规范

          
我来从产品视角帮你系统性查漏补缺，并把规范补齐为可落地的“产品+研发协同文档”。下面是在你已有框架上补充的关键内容与决策点，尽量保持你的结构与术语一致。

**总体定位与边界**
- 面向单组织（钉钉企业/学院）内的实验室与小组，非跨租户多组织。
- 课表以“学期-周次-日-节次”为基础，兼容单双周、临时调课、节假日停课与补课。
- 考勤以“按课次”为主，同时支持“自由打卡模式”（钉钉签到），二者的校验策略不同。

**2. 信息架构与术语（建议新增）**
- 组织/部门：映射钉钉组织与部门作为数据隔离的主维度。
- 小组（Group）：在实验室/部门下的工作单元；具备负责人（组长）、成员。
- 课程（Course）：包含课程名、授课教师、地点、节次、周次。
- 课表（Schedule）：课程在“学期-周次-节次”的具体排布，可来源于excel表格导入或手动录入。
- 学期（Term）：起止日期、教学周数、单双周标记。
- 考勤记录（Attendance）：打卡实体，包含打卡人、时间、课次/自由模式、校验状态、异常原因。
- 审批（Approval）：来自钉钉审批的请假/出差数据，映射到课程或时间段。

**1. 用户角色与权限体系（RBAC）细化**
- 普通成员（Member）
  - 查看个人课表与所属小组看板（仅自己或组汇总）。
  - 执行签到/签退（按课次或自由模式）。
  - 查看个人历史考勤与异常申诉结果。
- 小组长（Team Leader）
  - 查看本组看板与成员明细、导出本组报表。
  - 审核/确认本组成员的课表变更；处理本组考勤异常申诉。
  - 发起本组临时调课/取消（需管理员审核或规则内自动生效）。
- 管理员（Admin，实验室负责人）
  - 查看所有小组数据与看板；配置学期与全局基础数据。
  - 管理小组长与成员归属（基于钉钉部门映射）；设置考勤规则（迟到/早退阈值、宽限期）。
  - 管理课表导入模板与校验规则；审批跨组调课。
- 超级管理员（Super Admin）
  - 组织级配置与权限分配；组织架构同步策略与失败重试。
  - 数据隔离策略设定（按部门/自定义域）；全局审计与导出。
  - 配置系统集成（钉钉审批、消息、微应用开关）；数据留存策略。
- 建议明确“权限矩阵”：为每个关键动作标明可操作角色，如“导入课表：Admin/Super Admin”、“跨组调课审批：Admin”、“查看组织总览：Super Admin”等。

**3. 核心功能模块补充**

- 3.1 基础数据服务
  - 钉钉免登与用户绑定
    - 映射逻辑：首次登录读取钉钉用户信息与部门，创建或绑定本地账户。
    - 角色授予策略：默认 Member，Leader/Admin/Super Admin 通过配置或钉钉角色同步。
    - 容错与重试：钉钉API失败时的回退与提示；多设备登录一致性。
  - 更改提醒
    - 场景：成员更新个人课表；组长发起临时调课；管理员修改学期或规则。
    - 通知渠道：钉钉群机器人、工作通知、应用内消息；支持每日/每周汇总。
    - 审批链：是否需要Leader/Admin审核生效，或按低风险改动自动生效。
  - 智能课表引擎
    - Excel导入：提供模板下载；字段校验（课程名、地点、节次、周次、单双周、教师、班级/小组）。
    - 冲突检测：同一成员/教室/教师的时间冲突提示与解决策略（自动重排/人工确认/拒绝）。
    - 手动录入：快捷创建课程、批量设定周次与单双周；支持克隆与批量编辑。
    - 假期与调休规则：校历接入；节假日停课自动标记；调休自动改期或人工确认。
    - 版本与审计：课表版本化，变更历史可回溯与导出。

- 3.2 实时状态全景看板（Dashboard）
  - 视图：组织总览（Super Admin）、实验室/部门看板（Admin）、小组看板（Leader）、个人视图（Member）。
  - 维度与指标：应到/实到、迟到/早退、请假、缺勤；课程维度、人员维度、时间维度（日/周/月）。
  - 过滤与搜索：按小组/课程/教师/地点/异常类型；快速定位异常。
  - 实时性：课次开始前后窗口内实时更新；消息推送闭环。
  - 导出与分享：按视图导出Excel/PDF；带权限的分享链接；水印与过期控制。

- 3.3 考勤执行与校验（关键细化）
  - 校验策略（组合式）
    - WiFi校验：SSID与BSSID白名单；提示弱网或无法获取情况的处理。
    - 地理围栏：实验室地理范围（支持多点）；半径可配置；室内定位误差容忍。
    - 蓝牙Beacon：可选增强，解决WiFi/定位不可用场景。
    - 设备绑定：首次登录绑定设备；异常设备变更需审核。
    - 时间窗：签到提前/迟到宽限、签退提前/拖延阈值；跨节次连续课处理。
  - 风险与兼容性说明
    - iOS/Android在获取BSSID/SSID权限上的差异与系统版本限制；提供兜底方案（地理围栏+Beacon）。
    - 钉钉小程序能力边界：如无法直接读取部分硬件信息时的替代方案与产品提示。
  - 异常与申诉
    - 异常类型：网络不可用、越界打卡、迟到、早退、缺勤、设备变更。
    - 申诉流程：成员发起→Leader初审→Admin终审；证据附件与时限。
    - 自动化规则：审批通过自动修正考勤；重复异常预警。
  - 按课次与自由打卡
    - 按课次：必须依据课表当日当节；关联课程地点与教师。
    - 自由模式：用于科研/值班；仅关联地点/小组；规则更宽松但受限于地理围栏与时间窗。

- 3.4 钉钉生态深度集成（扩展）
  - 请假同步
    - 映射方式：钉钉审批表单字段与系统课表/时间段匹配；不同审批类型（事假/病假/出差）。
    - 冲突解决：请假覆盖对应课次，自动标记为“请假”并从应到人数中剔除。
    - 失败重试与审计：审批回调失败的队列与人工补偿；日志可查。
  - 消息与机器人
    - 变更通知、异常提醒、每日汇总；支持定时与触发式。
    - 可@相关责任人（组长/课程教师/管理员）。
  - 微应用配置
    - 在钉钉后台的应用可见性、权限范围、部门授权；多环境（测试/预发/生产）。

**数据模型与接口（高阶概览）**
- 主表：User、Group、Department、Course、Schedule、Term、Attendance、Approval、ChangeLog、DeviceBinding、RuleConfig、Location。
- 唯一键与关联
  - User与钉钉`userid`绑定；Department按钉钉`deptId`。
  - Schedule关联Course、Term、地点、周次/节次；Attendance关联User与Schedule或自由模式Location。
- 基础接口分层
  - 读：课表查询（个人/小组/学期）、看板查询（聚合）、审批状态、历史审计。
  - 写：导入/手动录入、考勤打卡、变更申请与审批、规则配置。
  - 回调：钉钉审批/组织架构变更事件；消息推送异步任务。

**流程设计（关键用户旅程）**
- 首次登录与绑定：免登→读取钉钉信息→角色判定→设备绑定（可跳过）→进入个人课表。
- 课表导入：下载模板→Admin上传→校验→冲突处理→版本生效→通知相关人。
- 临时调课：Leader发起→Admin审批→课表更新→通知并更新看板。
- 打卡与异常处理：成员在课次时间窗内打卡→规则校验→记录与看板刷新→异常自动与人工处理。
- 请假同步：审批通过→回调入库→匹配课次→看板与报表更新。

**报表与导出**
- 周/月/学期报表（小组/课程/人员维度）；异常分布与趋势。
- 课表版本差异对比；导出Excel/PDF；可选择字段与过滤条件。
- 数据留存与归档：保留期、可下载归档、管理员权限控制。

**安全与合规**
- 隐私数据分类与访问控制；最小权限原则。
- 日志与审计：关键操作与外部回调全量记录；可追溯。
- 数据加密与传输安全；异常访问与风控告警。
- 合规：个人信息保护、公示与同意机制；数据出境限制（如有）。

**性能与可靠性**
- 钉钉API限流与降级策略；本地缓存与重试队列。
- 看板聚合性能优化：按维度预聚合/离线任务，避免全量扫描。
- 高峰期（开学/导入）容量评估与任务排队提示。

**产品界面建议（关键页面）**
- 我的课表：周视图/日视图、快速打卡入口、冲突提示。
- 打卡页：显示校验策略状态（WiFi/定位/Beacon）、时间窗与异常提示。
- 小组看板：成员状态、异常列表、筛选与导出。
- 管理后台：学期与规则配置、导入与校验、审批与审计、组织同步。
- 变更中心：课表变更与审批、消息订阅管理。

**开放问题与待确认决策**
- 组织映射：小组是否严格对应钉钉部门，还是允许跨部门成员？
- WiFi能力边界：若终端无法获取BSSID时是否强制地理围栏+Beacon二选一？
- 请假审批表单字段标准化：是否制定统一模板以便准确匹配课次？
- 临时调课的自动化程度：哪些场景自动生效，哪些必须审批？
- 数据留存周期：考勤与审批数据的默认留存期限与导出权限。
