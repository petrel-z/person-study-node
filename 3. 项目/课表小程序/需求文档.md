# 概述
## 1.1项目背景

基于学校好多学习实验室，实验室在考勤时，由于每个同学的课程不统一，导致考勤人员在考勤时面临巨大的麻烦：汇总所有同学的课表，并生成相应的考勤表，且考勤结果需要考勤人员手动统计。这种机械重复的劳动大大浪费考勤人员的时间。
甚至，每个同学每周的课也不同，甚至会面临临时加课的情况，这也大大增加了考勤人员的负担。

## 1.2 目的和范围
本项目旨在帮助学校实验室的人员更加便捷的借助钉钉考勤，让同学们自动导入课表，根据同学们的课表自动给考勤人员生成考勤表，统计考勤信息，便于考勤人员考勤。

## 3 产品概要
### 3.1 产品介绍
本产品基于钉钉小程序开发，让用户能在钉钉上使用该小程序进行课表管理与考勤。方便考勤者与被考勤者，提高同学们的出勤率，鼓励大家积极出勤，营造良好的实验室学习氛围。
