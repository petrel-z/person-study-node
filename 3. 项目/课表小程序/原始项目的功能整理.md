# 功能分析

**项目定位**
- 面向校内用户的课表与课程管理小程序，帮助个人查看与维护课程，快速查询在某个时段“谁有课/谁无课”，并提供提醒与管理员配置能力。
- 目标用户包含普通用户与管理员，分别承担日常使用与平台配置职责。

**角色与权限**
- 普通用户
  - 浏览自己的课表与个人信息。
  - 维护个人课程（新增、修改、删除）。
  - 搜索他人并查看其课表与基础信息。
  - 设置课程提醒时间与是否开启。
  - 在特定周/时段查询“有课/无课”人员列表。
- 管理员
  - 配置上下课时间（各大节开始与结束）。
  - 管理筛选页展示的部门、地点、组别。
  - 维护管理员名单。
  - 同步学习场地信息、设置学期开始日期（第一周周一）。

**主页与入口**
- 课表
  - 展示本人的课表，支持按周查看。
  - 切换至“无课情况/有课情况”，查看全校或指定范围在某时段的人员分布。
  - 进入“高级筛选”，按部门、地点、组别、周、星期几、节次范围进行条件组合后查询。
- 搜索
  - 输入姓名或相关信息，搜索并选择某个用户。
  - 点击用户后进入该用户的详细信息页（含课表与基础资料）。
- 课程
  - 展示个人课程列表与底部提示。
  - 进入“添加课程”，设置周范围（开始/结束周、单双周）、星期几、上课大节次、课程名称、教师、地点、备注等。
- 我
  - 展示个人基本信息（姓名、院系、专业、班级、学号、性别、电话等）。
  - 入口：课程提醒设置、管理员平台、小程序使用说明。

**子页面功能**
- 用户详细信息
  - 展示该用户某一周的课表与详细资料。
  - 支持切换上一周/当前周/下一周。
- 课时段详情（按时间段）
  - 选择第几周、星期几、开始与结束大节次。
  - 查询该时段“无课”“有课”“请假”等人员列表，并分页加载。
- 课时段详情（按具体节次）
  - 固定某周某节，展示“无课”“有课”“迟到/缺勤”人员。
- 课程提醒设置
  - 选择统一的提前提醒时间（0/5/15/30/60分钟）。
  - 针对单门课程开启或关闭提醒。
- 课程维护
  - 添加或编辑课程信息，保存后回到课程列表。
- 导入他人课表
  - 搜索目标用户，选择后导入对方课表到本人账号。
- 高级筛选
  - 设置部门、地点、组别的显示与编辑。
  - 选择查询条件（周、星期几、开始与结束大节次）并应用到“有/无课情况”。
- 管理员平台
  - 设置上下课时间（每一大节的开始与结束）。
  - 管理筛选页可见的部门与地点。
  - 管理管理员名单（添加、删除）。
  - 同步场地数据、设置学期开始日期（用于正确计算“第几周”）。

**核心流程（面向用户）**
- 查看本周课表
  - 打开“课表” → 默认显示本人的课表 → 通过周选择查看其它周。
- 查询在某时段谁有课/无课
  - 打开“课表” → 切换到“有课/无课情况” → 进入“高级筛选”设置条件 → 查看结果列表 → 点进人员详情。
- 搜索某人并查看课表
  - 打开“搜索” → 输入关键词 → 点击某个用户 → 进入其“用户详细信息”页。
- 维护个人课程
  - 打开“课程” → 点击“添加课程” → 完善信息并保存 → 返回列表查看更新结果。
- 设置课程提醒
  - 打开“我” → 进入“课程提醒设置” → 选择提前提醒时间 → 针对课程开启/关闭提醒。
- 管理员配置
  - 打开“我” → 进入“管理员平台” → 根据需要进行时间配置、部门/地点管理、管理员管理、数据同步与学期开始日期设置。

**数据要素（面向需求）**
- 个人信息：姓名、院系、专业、班级、学号、性别、电话、头像。
- 课程信息：课程名、教师、地点、周范围（开始/结束周、单双周）、星期几、上课大节次、备注。
- 时间设定：每一大节的开始/结束时间；学期第一周周一日期；当前周（用于展示与查询）。
- 查询条件：周、星期几、开始与结束大节次、部门、地点、组别。
- 提醒设置：统一提前提醒分钟数；课程级别的提醒开关。

**使用体验与反馈**
- 列表与详情页提供底部提示，提示加载或列表已到底。
- 搜索与查询过程中显示加载状态，完成后关闭加载提示。
- 人员列表支持持续加载更多，避免一次展示过长。

**成功条件与可验证点**
- 课表与课程列表能按周正确显示，切换周后数据与日期一致。
- 在设定的时段查询到的“有课/无课/请假”人员名单与后台数据一致。
- 添加或编辑课程后，课程列表刷新显示最新内容。
- 提前提醒时间选择后能够生效，课程提醒开关与用户选择一致。
- 管理员配置（上下课时间、部门/地点显示、管理员名单、学期开始日期）更新后影响相关展示与查询。

**边界与例外**
- 学期开始日期未设置时，周次计算需有默认策略或给予用户提示。
- 当搜索无结果或筛选条件过于严格时，需提示“未找到符合条件的人员或课程”。
- 当网络请求失败，需提示重试或联系管理员。
- 课程时间冲突或重复时，保存流程需提示用户确认或进行合并处理（如需）。

**待确认事项（建议与补充）**
- “有课/无课情况”的统计范围与默认筛选（全校/本院系/本地点）。
- 课程提醒的触发方式与触发时机（前台提醒、后台推送、是否依赖钉钉日历/消息）。
- 导入他人课表的权限与覆盖策略（合并还是替换；是否允许撤销导入）。
- 管理员范围与审批流程（谁可成为管理员、如何授权与回收）。

# 功能实现


**项目概览**
- 小程序主题为课程与课表管理，支持个人课表浏览、课程维护、人员有/无课查询、以及管理员配置。
- 底部导航包含四个主入口：`课表`、`搜索`、`课程`、`我`，对应四个核心功能域。
- 大量使用自定义组件与 `mini-ali-ui` 组件，页面间通过 `dd.navigateTo` 跳转，部分数据通过 `dd.httpRequest` 访问后端接口。

**导航与结构**
- 主页面
  - `pages/schedule/index`：课表总览与有/无课情况。
  - `pages/operate/index`：搜索用户并查看详情。
  - `pages/course/index`：我的课程列表与课程维护入口。
  - `pages/profile/index`：个人信息、管理员入口、课程提醒设置。
- 子页面（部分）
  - `lectureDetail` / `lectureDetailByTime`：按周/节次的人员有无课详情。
  - `userDetail`：指定用户的课表与基础信息。
  - `addCourse`：添加/编辑课程。
  - `inputFromOtherUserCourse`：导入他人课表。
  - `filterOperate`：高级筛选操作（部门/地点/组、周/节次范围）。
  - 管理员相关：`adminPlatformPage`、`adminUserManagementPage`、`lectureTimeManagePage`、`departmentManagmentPage`、`locationManagmentPage`。
  - 其他：`courseCalendarPage`（课程提醒设置）、`miniProgramDocumentPage`（说明文档）。

**核心功能模块**
- 课表（`pages/schedule`）
  - 顶部 `TopBar` 三种视图切换：`我的课表`、`无课情况`、`有课情况`。
  - 周选择器 `MyPicker` 控制当前周；`ScheduleTable`/`ScheduleTableProgress` 展示课程格局与统计。
  - 支持点击单元格获得详情（`onGetClickedData`）；非“我的课表”视图可进入“高级筛选”（跳转 `filterOperate`）。
- 搜索（`pages/operate`）
  - 使用 `SearchBox` 搜索用户；点击结果跳转用户详情（携带 `userid` 与当前周 `app.systemConfig.nowWeek`）。
  - 统一的加载态处理（`dd.showLoading`/`dd.hideLoading`）。
- 我的课程（`pages/course`）
  - 展示 `course-card` 列表；支持“添加课程”按钮，进入 `addCourse`。
  - 页面底部提示（`am-footer`）；引入 `am-calendar`（用于显示或选择日期）。
- 个人信息与入口（`pages/profile`）
  - 展示用户基础信息（姓名、院系、班级、学号、性别、电话等）。
  - 入口：
    - 课程提醒设置（`courseCalendarPage`）。
    - 管理员平台（`adminPlatformPage`，依据 `isAdmin` 控制显示）。
    - 小程序说明文档页（`miniProgramDocumentPage`）。
- 课程提醒（`pages/subPages/courseCalendarPage`）
  - 设置全局提前提醒时间（0/5/15/30/60 分钟）；可对单课程开关提醒。
  - 使用 `my-picker-time`、`am-list`、`am-title` 等组件展示与交互。
- 人员详情与有/无课查询（`lectureDetail`、`lectureDetailByTime`、`userDetail`）
  - `lectureDetail`：固定某周某节，展示无课、有课、迟到/缺勤人员；支持分页加载与列表更新。
  - `lectureDetailByTime`：按周、星期几、开始/结束节次范围，查询人员有/无课，使用后端接口 `course/findUserByClassInPeriod`。
  - `userDetail`：展示指定用户在一周的课表与详细信息；支持上一周/当前周/下一周切换（`BackForwardButtonGroup`）。
- 管理员平台（`pages/subPages/adminPlatformPage`）
  - 操作项：
    - 设置上下课时间（进入 `lectureTimeManagePage`）。
    - 筛选页部门显示管理（`departmentManagmentPage`）。
    - 筛选页地点显示管理（`locationManagmentPage`）。
    - 管理员增删（`adminUserManagementPage`）。
    - 同步学习场地信息、设置学期开始日期（第一周周一）。
  - 使用 `am-list`、`list-item`、`am-footer` 等 UI 组件。
- 课程维护（`pages/subPages/addCourse`）
  - 支持添加/修改课程；配置周范围与周频率（单双周/单周/双周）、星期几与大节次、课程名称、教师、地点与备注。
  - 交互数据：`operateType`、`page_title`、`executeButtonName` 等决定页面状态与按钮文案。
- 课表导入（`pages/subPages/inputFromOtherUserCourse`）
  - 使用 `user-search-box` 搜索他人并导入其课表，带底部说明（`am-footer`）。
- 高级筛选（`pages/subPages/filterOperate`）
  - 支持配置部门、地点、组别显示与编辑；选择周、星期、开始/结束大节（用于生成查询条件）。
- 管理员管理（`pages/subPages/adminUserManagementPage`）
  - 管理员列表（姓名、头衔、班级地点、专业、头像、学院、所属组等），并提供搜索与操作入口（`am-swipe-action`、`am-list`）。

**组件与UI**
- 自定义组件
  - 结构展示：`ScheduleTable`、`ScheduleTableProgress`、`CourseCard`、`UserTable`、`UserInfoTable`、`DataShowPanel`。
  - 交互控件：`TopBar`、`MyPicker`、`MyPickerTime`、`ItemButton`、`ItemInput`、`BackForwardButtonGroup`、`SearchBox`、`UserSearchBox`。
- 第三方组件（`mini-ali-ui`）
  - 列表与条目：`am-list`、`list-item`。
  - 反馈与装饰：`am-footer`、`am-title`、`am-tag`、`am-icon`、`am-pagination`。
  - 日期相关：`am-calendar`。

**数据与交互逻辑**
- 页面间跳转：统一使用 `dd.navigateTo`，例如从搜索跳转到 `userDetail`，从“我”跳到提醒设置或管理员平台。
- 后端接口：在详情与筛选场景下使用 `dd.httpRequest` 查询有/无课人员列表（示例：`/course/findUserByClassInPeriod`）。
- 全局配置：通过 `getApp()` 访问 `app.systemConfig`（如 `nowWeek`），以及 `app.BASE_URL`、`app.temporary` 等共享数据。
- 课表渲染数据：表格单元为 `{ top, mid, bottom, percent }` 的结构；`lessonTimes` 管理各大节的开始/结束时间。

**角色与权限**
- 普通用户：浏览个人课表、查看人员详情、维护个人课程、设置课程提醒、搜索用户。
- 管理员：进入管理平台进行时间、部门、地点、管理员等配置；支持数据同步与学期参数设置。

**用户路径示例**
- 查看本周课表：打开 `课表` → 顶部选择“我的课表” → 周选择器点击目标周。
- 查询某时段有无课人员：`课表` → 顶部选择“无课/有课情况” → 高级筛选 → 选择条件 → 跳转到详情页。
- 搜索并查看某人课表：`搜索` → 输入关键词 → 点击结果 → 进入 `用户详细信息`。
- 维护个人课程：`课程` → 查看列表 → 点击“添加课程” → 在 `课程操作` 页面填写并保存。
- 设置课程提醒：`我` → 点击“课程提醒设置” → 配置全局提前提醒或单课程开关。
- 管理员配置：`我` → “管理员界面” → 管理上下课时间、部门/地点显示、管理员增删、同步与学期日期设置。
