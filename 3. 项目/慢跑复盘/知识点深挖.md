  2. 复杂SKU管理系统 ⭐⭐⭐⭐⭐

  技术价值： 算法思维+复杂业务逻辑处理能力

  可写内容：
  - 实现三种规格模式：统一规格、单规格、多规格的动态切换
  - 使用笛卡尔积算法生成多规格组合（技术难点）
  - SKU与购物车的联动同步机制（避免数据不一致）

  核心算法：
  // 生成规格组合（笛卡尔积）
  const generateCombos = (categories: CategoryDef[]) => {
    let acc = categories[0].values.map(v => [v]);
    for (let i = 1; i < categories.length; i++) {
      const next = [];
      for (const a of acc) {
        for (const v of categories[i].values) {
          next.push([...a, v]);
        }
      }
      acc = next;
    }
    return acc;
  };

  简历描述示例：
  设计并实现多规格商品管理系统，支持统一规格/单规格/多规格三种模式。通过
  笛卡尔积算法动态生成SKU组合，解决规格爆炸问题，建立SKU与购物车的联动
  同步机制，保证数据一致性
