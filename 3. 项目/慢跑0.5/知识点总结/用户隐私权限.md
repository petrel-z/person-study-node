用户必须同意隐私政策
才能调用wx.login
微信要求开发者在用户同意隐私政策后，需主动调用 `wx.setUserAgreePrivacy(true)` 同步状态。

```js
// 1. 检查用户是否已同意隐私政策
const hasAgreedPrivacy = wx.getStorageSync('hasAgreedPrivacy') === true

if (!hasAgreedPrivacy) {
  // 2. 显示自定义隐私协议弹窗
  showPrivacyModal().then(() => {
    // 3. 用户同意后，同步状态到微信
    wx.setUserAgreePrivacy(true)
    wx.setStorageSync('hasAgreedPrivacy', true)
    
    // 4. 再调用登录接口
    wx.login({
      success: (res) => {
        console.log('登录成功', res.code)
      }
    })
  })
} else {
  // 已同意，直接登录
  wx.login()
}
```
