1. 查询参数
```ts
// 传递
uni.navigateTo({
url: `/pages/tab/user/balance/detail/index?item=${itemStr}`
});
// 接受
onLoad((options) => {
	if (options.item) {
		const item = JSON.parse(decodeURIComponent(options.item));
		console.log('接收到的数据:', item);
}
});
```
```ts
// 传递数据

const lookDetail = () => {
getApp().globalData.balanceItem = props.item;
uni.navigateTo({
url: '/pages/tab/user/balance/detail/index'
});
};

// 接收数据

onMounted(() => {
const item = getApp().globalData.balanceItem;
if (item) {
console.log('接收到的数据:', item);
// 使用完后清除
delete getApp().globalData.balanceItem;
}

});
```

- URL参数 ：简单直接，但有长度限制，适合简单数据
- 事件总线 ：灵活，但需要注意内存泄漏
- 全局数据 ：简单，但容易造成数据污染
- 本地存储 ：持久化，但需要手动清理
- Pinia ：最规范，适合复杂应用
