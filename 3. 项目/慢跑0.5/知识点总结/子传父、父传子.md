props父传子：
``` js
// 父组件
<children msg="123"> </children>


// 在子组件中
const props = definedProps({
	msg: boolean,
})
```

emit子传父:
在父组件中，点击了子组件
通过子组件emit 一个值
父组件通过方法就能获取这个值
``` js
// 父组件
<children @child-click="parentFn"/>
const parentFn = (value) => 
// value就是子组件传过来的数据
}

//子组件
<view>
	<button @click="childFn">
		
	</button>
</view>
const emit = definedEmit(['child-click])
const childFn = () => {
	emit('chilc-click', 1);
}
```
总结：
在子组件中用definedEmit定义一个 与父组件的通信媒介
子组件触发事件时，会通过emit来传入媒介，以及值。
父组件通过这个媒介，用自定义方法的参数来接受这个值

父子双向绑定：
先父传子，再子传父
本质上是：父组件里的数据，先通过props的方式，传入子组件，子组件再通过emit将这个数据传给父组件，不管是父子组件里的数据任何一方改变，对方都能接收


所有defineProps定义的props都是响应式的
