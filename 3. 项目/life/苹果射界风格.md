
整体遵循苹果iOS+macOS原生设计语言，以**Liquid Glass液态玻璃+空间扁平化**为核心，坚持内容优先原则，打造极简、通透、高质感的页面视觉；配色采用浅色/深色双模式动态适配，低饱和莫兰迪调为主，高对比度保证可读性；布局充足留白、层级清晰，全元素统一圆角，搭配轻量自然的物理动效，无多余装饰，整体视觉干净、连贯、适配多端，符合苹果生态的审美与交互逻辑。


### 一、核心设计风格定调
1. 整体调性：**极简通透、内容优先、空间层次、原生质感**，延续苹果iOS 26+macOS Tahoe 26的Liquid Glass液态玻璃设计语言，拒绝冗余装饰，所有视觉元素为内容服务；
2. 核心质感：半透明高斯模糊毛玻璃效果（适用于导航栏、卡片、侧边栏）+ 微妙轻阴影（非厚重投影，仅用于区分元素层级）+ 低反光液态透明质感（适用于交互组件）；
3. 形态规范：全页面元素统一圆角设计（大模块16px、中组件8px、小控件4px，遵循苹果黄金圆角比例），无直角元素，视觉柔和连贯；
4. 视觉层级：通过**背景色分级、透明度差异、轻阴影深浅、元素间距**区分主次，核心内容视觉占比≥70%，次要信息弱化但不缺失。

### 二、色彩体系规范（双模式适配，全色值贴合苹果原生）
#### 基础规则
1. 支持**浅色模式（日间）、深色模式（夜间）** 自动切换，可自定义1种强调色（从苹果原生11色中选：红/橙/黄/绿/薄荷绿/青/蓝/靛蓝/紫/粉/棕），默认强调色为苹果原生经典蓝（#007AFF）；
2. 全配色遵循**低饱和、高对比度**，浅色模式无过亮纯白，深色模式无纯黑，减少视觉疲劳，符合苹果护眼色彩逻辑；
3. 采用苹果**三级背景色系统**，跨页面统一使用，不随意新增背景色阶。

#### 具体配色规范
##### 浅色模式（主模式，适配日间/明亮环境）
- 一级背景：浅灰底（#F5F5F7），用于页面主内容区、全屏背景，替代纯黑纯白，降低反光；
- 二级背景：浅灰微深（#E8E8ED），用于内容分组卡片、模块分隔区；
- 三级背景：浅灰偏白（#FFFFFF），用于核心交互组件、重点内容卡片；
- 文本色：主文本（#1D1D1F，深灰近黑）、次文本（#86868B，中灰）、三级文本（#AEAEB2，浅灰）、链接/强调文本（默认#007AFF，自定义强调色替代）；
- 分隔线/边框：极浅灰（#EFEFF4），低存在感，仅用于模块轻分隔，拒绝粗边框；
- 交互态色：按钮hover（强调色浅调+10%透明度）、按钮选中（强调色纯调）、禁用态（全元素降饱和+50%透明度）。

##### 深色模式（副模式，适配夜间/暗光环境）
- 一级背景：深灰底（#1C1C1E），苹果原生深色主背景，非纯黑，减少屏幕蓝光；
- 二级背景：深灰微浅（#2C2C2E），用于内容分组卡片、模块分隔区；
- 三级背景：深灰偏深（#3A3A3C），用于核心交互组件、重点内容卡片；
- 文本色：主文本（#FFFFFF，纯白）、次文本（#929297，中灰）、三级文本（#636366，深灰）、链接/强调文本（默认#0A84FF，苹果深色模式经典蓝，自定义强调色提亮20%）；
- 分隔线/边框：极深灰（#333333），低存在感，与背景融合度高；
- 交互态色：按钮hover（强调色深调+10%透明度）、按钮选中（强调色纯调）、禁用态（全元素降饱和+50%透明度）。

##### 辅助色规范
- 功能色：成功（苹果原生绿#34C759）、警告（苹果原生黄#FFCC00）、错误（苹果原生红#FF3B30）、信息（苹果原生蓝#007AFF），均采用低饱和版本，不刺眼；
- 渐变色：仅用于页面首屏banner/视觉焦点区，采用苹果原生同色系渐变（如蓝系#007AFF→#5AC8FA），渐变柔和，无高对比撞色渐变。

### 三、布局规范（贴合苹果内容优先，适配多端）
1. 留白原则：**大间距定框架，小间距定细节**，页面上下左右边距≥20px（移动端）/≥40px（桌面端），模块之间间距≥32px，组件之间间距≥16px，文本内边距≥8px，拒绝拥挤布局；
2. 排版结构：采用**居中对称布局**（苹果原生主流），部分功能区可左对齐（如列表、表单），整体视觉重心居中，符合用户视觉习惯；
3. 模块设计：全页面采用**卡片式模块化**设计，卡片统一毛玻璃半透明+轻阴影+圆角，卡片内内容留白充足，无满铺设计；
4. 多端适配：遵循**响应式流体布局**，桌面端（≥1200px）多列分栏，平板端（768px-1199px）双列分栏，移动端（<768px）单列通栏，元素大小随屏幕等比缩放，核心内容始终在视觉黄金区域；
5. 导航布局：桌面端采用顶部导航栏（毛玻璃半透明）+ 侧边栏（可选），移动端采用顶部导航栏（毛玻璃半透明）+ 底部tab栏（简洁图标+文字），导航栏高度统一（桌面端60px、移动端44px，符合苹果交互尺寸）。

### 四、视觉组件规范（全组件贴合苹果原生，统一质感）
所有组件遵循**极简形态、通透质感、清晰交互**，无多余纹理/装饰，核心组件规范如下：
1. 按钮：分为主按钮（纯色填充，强调色，圆角8px）、次按钮（描边式，强调色描边，无填充，圆角8px）、文字按钮（无描边无填充，仅文字，圆角4px）；按钮大小统一（桌面端48px*32px，移动端44px*28px），hover/点击/禁用态视觉反馈清晰，无夸张效果；
2. 输入框/选择框：毛玻璃半透明背景，轻描边（浅色模式#EFEFF4，深色模式#333333），圆角8px，聚焦态为强调色描边（2px），输入内容左对齐，内边距上下左右8px，无多余装饰；
3. 卡片：毛玻璃半透明（高斯模糊10px）+ 轻阴影（opacity:0.1，blur:8px），圆角16px，卡片内边距≥20px，可根据内容分为大卡片（核心内容）、中卡片（分组内容）、小卡片（次要信息）；
4. 弹窗/模态框：居中显示，毛玻璃半透明背景，轻阴影，圆角16px，遮罩层为半透明黑（浅色模式opacity:0.3，深色模式opacity:0.5），弹窗内内容留白充足，关闭按钮为极简图标（无衬线）；
5. 列表：左对齐，行高统一，列表项之间无分隔线（或极浅分隔线），选中项为强调色轻背景（opacity:0.1），无高亮色块，列表图标为线性极简图标（与苹果原生图标风格一致）；
6. 图标：全页面采用**线性极简图标**（描边2px），无面性图标（仅视觉焦点区可少量使用），图标大小统一（24px*24px/16px*16px），与文字对齐居中，风格连贯，贴合苹果原生图标审美；
7. 进度条/加载动效：极简线性进度条（强调色，高度2px），加载动效为苹果原生环形加载（无多余动画），轻量、无卡顿。

### 五、文字排版规范（贴合苹果SF Pro字体体系，层级清晰）
1. 字体选择：优先使用苹果原生字体**SF Pro（桌面端）/SF Compact（移动端）**，无该字体时替换为无衬线字体（Inter/思源黑体），全页面字体统一，无多字体混用；
2. 字重分级：遵循苹果原生字重，分为UltraLight(100)、Light(300)、Regular(400)、Medium(500)、Semibold(600)、Bold(700)，仅用**Regular/Medium/Semibold/Bold**四级，避免字重过多导致层级混乱；
3. 字号规范（移动端/桌面端双规，单位px）：
    - 桌面端：标题H1(32/Semibold)、H2(24/Medium)、H3(20/Medium)、正文(16/Regular)、次要文本(14/Regular)、辅助文本(12/Regular)；
    - 移动端：标题H1(24/Semibold)、H2(20/Medium)、H3(18/Medium)、正文(16/Regular)、次要文本(14/Regular)、辅助文本(12/Regular)；
4. 行高与字间距：标题行高1.2倍，正文行高1.5倍，次要/辅助文本行高1.4倍；字间距仅标题可轻微拉开（+0.5px），正文/小文本字间距0，保证可读性；
5. 文本排版：标题居中/左对齐，正文/列表左对齐，文本颜色严格遵循色彩体系的文本色分级，无自定义文本色，大段文本无首行缩进，段间距≥16px。

### 六、动效设计规范（苹果原生物理动效，轻量自然，无冗余）
1. 核心原则：**自然流畅、物理直觉、轻量低耗**，动效为交互服务，不抢内容焦点，所有动效时长统一（300ms），过渡顺滑，无卡顿/夸张/闪烁效果；
2. 基础动效：页面切换（淡入淡出+轻微滑动）、组件出现（淡入+从下往上轻微平移，opacity从0到1）、组件消失（淡出+轻微收缩，opacity从1到0）；
3. 交互动效：按钮hover（轻微缩放+透明度变化，scale=1.02，opacity=0.9）、按钮点击（轻微下压，scale=0.98）、卡片hover（轻微上浮+阴影加深，translateY=-2px，shadow opacity+0.1）、滚动动效（顺滑滚动，无卡顿，导航栏随滚动从透明变半透明）；
4. 特殊动效：毛玻璃元素随页面滚动/交互，背景轻微模糊度变化（±2px），营造液态玻璃的空间感；下拉刷新/上拉加载为苹果原生极简动效，无自定义复杂动画；
5. 动效禁用：大段文本区、核心内容区无动效，避免干扰阅读；深色模式切换为淡入淡出（300ms），无色彩闪烁。

### 七、细节质感规范（打造苹果式精致，拒绝粗糙）
1. 阴影：仅用于区分元素层级，所有阴影为**轻量弥散阴影**，无硬阴影/厚重阴影，阴影色为黑/白（浅色模式黑阴影，opacity0.1；深色模式白阴影，opacity0.05）；
2. 透明度：毛玻璃元素透明度统一为0.8-0.9，遮罩层透明度为0.3-0.5，交互组件禁用态透明度为0.5，透明度变化连贯，无突兀跳变；
3. 边框：全页面无粗边框，仅输入框/选择框有1px轻描边，分隔线为1px极浅线，部分组件可无边框（纯靠间距/阴影区分）；
4. 图片：所有图片统一圆角（与所在模块一致），图片加载为渐进式淡入，无拉伸变形，图片背景与页面背景融合，核心图片无水印/多余装饰；
5. 视觉一致性：全页面元素的圆角、间距、字重、动效时长、透明度统一，无跨模块的样式混乱，符合苹果生态的“全局一致性”设计逻辑。

### 八、交互体验规范（贴合苹果原生交互，简洁易用）
1. 操作反馈：所有点击/hover/滑动操作均有清晰视觉反馈，无无反馈操作，反馈效果轻量（如按钮变色、卡片上浮、文字高亮）；
2. 手势适配：移动端支持苹果原生手势（下拉刷新、上拉加载、左滑删除/编辑、右滑返回），桌面端支持鼠标悬停/滚轮顺滑滚动，手势操作符合用户使用习惯；
3. 加载体验：页面加载为骨架屏（极简线框，与页面布局一致），无空白加载，骨架屏动效为轻量闪烁，加载完成后淡入内容；
4. 容错设计：输入框内容错误有轻量提示（文字+功能色，无弹窗遮挡），误操作可一键返回，核心操作有二次确认（如删除/提交），提示框为极简毛玻璃样式，贴合整体风格。
