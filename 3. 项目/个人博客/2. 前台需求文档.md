# 个人博客系统 — 前台需求文档（PRD）

版本：v1.0  
模块：前台系统（Visitor Side）  
负责人：博主

---

# 一、项目背景

构建一个面向技术读者的个人博客前台系统，用于：

- 展示技术文章
    
- 提供良好的阅读体验
    
- 支持互动（评论 / 点赞）
    
- 提供内容发现能力（搜索 / 排行榜 / 分类）
    
- 建立个人技术品牌
    

---

# 二、项目目标

## 2.1 核心目标

- 提升阅读体验
    
- 提高文章可发现性
    
- 提供基础互动能力
    
- 支持移动端访问
    
- 支持暗黑模式
    
- 支持国际化扩展
    

## 2.2 成功指标（可选）

- 平均阅读时长提升
    
- 评论转化率提升
    
- 搜索使用率
    
- 页面加载时间 < 2s
    

---

# 三、用户角色

## 3.1 访客

特征：

- it技术从业者或学习者
    
- 通过搜索引擎或社交分享进入
    
- 主要行为：阅读 / 搜索 / 评论 / 点赞 / 分享
    

---

# 四、信息架构

```
首页
```

# 五、功能模块说明

---

# 5.1 首页（文章列表页）

## 功能目标

展示最新文章，提供内容入口。

## 页面内容

每篇文章卡片包含：

- 标题
    
- 摘要（优先使用文章概述，否则截取前200字）
    
- 分类
    
- 标签
    
- 发布时间
    
- 阅读量
    
- 点赞数
    
- 评论数
    
- 封面图（可选）
    
- 预计阅读时间（字数 / 300）
    

## 交互行为

- 点击标题进入详情页
    
- 支持分页（每页10篇）
    
- 默认按发布时间倒序
    

## 性能要求

- 首屏加载 < 2 秒
    
- 图片懒加载
    
- 支持缓存
    

优先级：高

---

# 5.2 文章详情页

## 页面结构

```
标题
文章元信息
正文
目录（右侧）
点赞区
评论区
相关推荐
```

---

## 正文渲染要求

- 支持 Markdown 渲染
    
- 支持代码高亮
    
- 代码块一键复制
    
- 图片自适应
    
- 自动生成目录（基于 h1/h2/h3）
    

目录要求：

- 可折叠
    
- 平滑滚动定位
    
- 当前章节高亮
    
- 移动端隐藏为抽屉
    

---

## 阅读量统计

规则：

- 同一 IP 10 分钟内只计一次
    
- 前端展示累计值
    

---

## 点赞功能

- 每 IP 每篇仅一次
    
- 实时更新点赞数
    
- 防刷机制
    

---

## 评论功能

### 输入规则

- 昵称必填
    
- 头像可选（默认头像）
    
- 内容 ≤ 500 字
    
- 验证码防 spam
    

### 展示规则

- 按时间倒序
    
- 支持一级回复
    
- 支持分页
    

### 安全机制

- XSS 过滤
    
- 敏感词过滤
    
- 频率限制（1分钟1条/IP）
    

优先级：高

## 上一篇 / 下一篇导航

### 功能目标

提升阅读连续性，增强同主题文章浏览体验。

---

## 展示位置

位于文章底部，评论区上方。

示例：

← 上一篇：xxx标题  
  
下一篇：xxx标题 →

---

### 逻辑规则

#### 情况一：从分类页进入文章

- 上一篇 / 下一篇在“当前分类”内切换
    
- 按发布时间排序（与分类页一致）
    
- 若为当前分类第一篇：
    
    - 上一篇按钮隐藏或禁用
        
- 若为当前分类最后一篇：
    
    - 下一篇按钮隐藏或禁用
        

---

#### 情况二：从首页或搜索页进入文章

- 上一篇 / 下一篇按全站时间顺序切换
    
- 默认按发布时间倒序
    

---

### 交互行为

- 点击按钮无整页刷新（可选）
    
- 自动滚动到文章顶部
    
- URL 更新为新文章地址
    

---

### 边界处理

- 若无上一篇或下一篇，对应按钮置灰
    
- 避免跨分类跳转（仅在分类上下文内切换）

---

# 5.3 分类页
## 5.3.1 分类总览页

路径：

/categories

### 功能说明

展示所有文章分类，供访客按主题浏览。

### 页面展示内容

每个分类卡片包含：

- 分类名称
    
- 分类描述（可选）
    
- 当前分类文章数量
    
- 最近更新时间（可选）
    

### 交互行为

- 点击分类 → 进入该分类的文章列表页
    

优先级：中

---

## 5.3.2 分类文章列表页

路径：

/category/{name}

### 功能说明

展示当前分类下的文章列表。

### 页面展示内容

与首页文章列表一致：

- 标题
    
- 摘要
    
- 发布时间
    
- 阅读量
    
- 点赞数
    
- 评论数
    
- 预计阅读时间
    
- 封面图（可选）
    

### 排序规则

- 默认按发布时间倒序
    
- 支持分页（每页10篇）
    

### 交互行为

- 点击文章 → 进入文章详情页
    
- 保留当前分类上下文（用于上一篇/下一篇切换）
优先级：高
---

# 5.4 搜索页

## 功能

- 支持标题 + 内容全文搜索
    
- 支持模糊匹配
    
- 高亮关键词
    
- 无结果提示
    

## 交互

- 输入防抖
    
- 回车触发
    
- 支持清空
    

优先级：高

---

# 5.5 热度排行榜页

## 功能

展示热门文章前10。

## 排序规则

热度计算公式：

```
热度 = 阅读量 × 0.6 + 点赞 × 0.3 + 评论 × 0.1
```

## 榜单类型

- 总榜
    
- 本月榜
    

优先级：中

---

# 5.6 创作记录页

灵感来源：GitHub 提交日历

## 功能

- 按天统计发布 / 编辑次数
    
- 热力图展示
    
- 支持年份切换
    
- 点击某日查看详情
    

## 时间轴

展示：

- 发布文章
    
- 编辑文章
    
- 删除文章
    

优先级：中

---

# 5.7 关于我页面

功能：

- 展示个人介绍
    
- 支持 Markdown
    
- 展示头像
    
- 社交链接
    

优先级：低

---

# 5.8 主题切换

支持：

- 浅色模式
    
- 深色模式
    
- 自动跟随系统
    

规则：

- 用户选择持久化
    
- 页面刷新保持一致
    

优先级：中

---

# 5.9 多语言支持

支持：

- 中文
    
- 英文
    

范围：

- 菜单
    
- 系统提示
    
- 按钮文案
    

不包含：

- 文章自动翻译
    

优先级：低

---

# 5.10 分享功能

支持：

- 复制链接
    
- 微信分享
    
- 微博分享
    

分享内容包含：

- 标题
    
- 摘要
    
- 封面图
    

优先级：低

---

# 5.11 RSS 支持

路径：

```
/rss.xml
```

规则：

- 发布文章自动更新
    
- 包含标题 / 链接 / 摘要 / 时间
    

优先级：低
