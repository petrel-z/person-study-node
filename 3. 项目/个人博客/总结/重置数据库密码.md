# 正确重置 MySQL 8.0 密码（OpenCloudOS 专用）

## 1. 先停掉 MySQL（你这步是对的）

bash

运行

```
systemctl stop mysqld
```

## 2. 用官方推荐方式跳过密码验证

bash

运行

```
mysqld --skip-grant-tables --user=mysql &
```

## 3. 直接免密登录 MySQL

bash

运行

```
mysql -u root
```

## 4. 进入 mysql 库

sql

```
use mysql;
```

## 5. 清空旧密码（关键）

sql

```
update user set authentication_string='' where user='root';
```

## 6. 刷新权限

sql

```
flush privileges;
```

## 7. 退出

sql

```
exit;
```

## 8. 杀掉临时免密进程

bash

运行

```
pkill mysqld
```

## 9. 正常启动 MySQL

bash

运行

```
systemctl start mysqld
```

## 10. 无密码登录，设置新密码

bash

运行

```
mysql -u root
```

然后执行：

sql

```
ALTER USER 'root'@'localhost' IDENTIFIED BY '041123';
flush privileges;
exit;
```

---

# ✅ 完成！现在你可以正常登录了

bash

运行

```
mysql -u root -p041123
```

---

## 最重要：你要远程 Navicat 连接，必须再执行这 2 句

bash

运行

```
mysql -u root -p041123
```

然后：

sql

```
CREATE USER 'root'@'%' IDENTIFIED BY '041123';
GRANT ALL ON *.* TO 'root'@'%';
FLUSH PRIVILEGES;
```
